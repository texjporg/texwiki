## 使い方 {#q073bbcd}

- [TeX/PackageFile/lmodern - PukiWiki](http://glc.l.u-tokyo.ac.jp/pukiwiki/index.php?TeX%2FPackageFile%2Flmodern)
- [LaTeX で Latin Modern Mono Light を使う](http://blog.wgag.net/112.html)

```
\usepackage[T1]{fontenc}
\usepackage{lmodern}
```

詳細は

```
texdoc lm
```

で確認してください．<br>
