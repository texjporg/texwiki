# Latin Modern

## Latin Modern {#dd869f5d}

Latin Modern は，Comupter Modern や [CM-Super](/cm-super/) に代わるフォントです．
[METAFONT](/METAFONT/) ソースから直接 PostScript Type 1 に変換されたもので，CM-Super より品質が優れています．
また，OpenType 形式も配布されています．

## 使い方 {#q073bbcd}

- [TeX/PackageFile/lmodern - PukiWiki](http://glc.l.u-tokyo.ac.jp/pukiwiki/index.php?TeX%2FPackageFile%2Flmodern)
- [LaTeX で Latin Modern Mono Light を使う](http://blog.wgag.net/112.html)
- [XeLaTeX：欧文フォントについての補足 \[電脳世界の奥底にて\]](http://zrbabbler.sp.land.to/xelatex1.html)

```
\usepackage[T1]{fontenc}
\usepackage{lmodern}
```

詳細は

```
texdoc lm
```

または

```
texdoc lmodern
```

で確認してください．
