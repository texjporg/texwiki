# 変換ツール

## いろいろな変換ツール {#qb4d5c4e}

ここでは，TeX と合わせて用いることができる便利な変換ツールをまとめます．

<strong>目次</strong>

## ビットマップ画像 (ラスターイメージ) ←→ PDF/EPS {#w1278ce9}

JPEG は EPS2（正確には PostScript Level 2 の EPS）にするとサイズがあまり増えません．

- [Poppler](/Poppler/) (pdftocairo)
    - Linux Mint, Debian では poppler-utils にコマンドが収録されています．
    - pdftocairo  - Portable Document Format (PDF) to PNG/JPEG/PDF/PS/EPS/SVG using cairo
- [MuPDF](/MuPDF/) (mutool)
    - Linux Mint, Debian では mupdf-tools にコマンドが収録されています．
    - mutool draw - render PDF/XPS/CBZ documents (PDF → PNG)
- [dktools](https://sourceforge.net/p/dktools/wiki/Home/)
    - bmeps (PNG 等 → PDF/EPS1, 2, 3．[TeX Live](</TeX Live/>) にも収録されています)
- [sam2p](https://github.com/pts/sam2p)
    (ビットマップ → PDF/EPS．[TeX Live](</TeX Live/>) にも収録されています)
    - TeX Live 2025 の 32-bit 版の sam2p.exe を実行するとアプリケーション エラーが発生してアプリケーションを正しく起動できない場合は bmeps を使用してください。--&gt; \[[ViewVC\] Log of: texlive/trunk/Master/bin/windows/sam2p.exe](https://svn.tug.org/texlive/trunk/Master/bin/windows/sam2p.exe?view=log)、[sam2p.exe(64bit)の動作が不調](https://okumuralab.org/tex/mod/forum/discuss.php?d=1801)、[sam2p broken (on windows)](https://tug.org/pipermail/tex-live/2023-October/049548.html)
- [potrace](https://potrace.sourceforge.net/)
    (グレースケールbmp → PDF/EPS/PS/SVG．)

- [ImageMagick](/ImageMagick/)
    - magick foo.jpg eps2:foo.eps とすると EPS2 になる
    - mogrify -format pdf \*.jpg とすると，フォルダ（ディレクトリ）内の全 jpg を pdf に変換する（上書きされない）
- [EPS-conv](https://phys.edu.gunma-u.ac.jp/terasima/epsconv.htm)
    (寺嶋 容明 さん)
    (Windows用, BMP/JPEG/PNG/GIF → EPS, Susie plug-in対応)
    - [TeXを便利に使うツール類#EPS-conv(画像変換ツール)](http://c.nagaokaut.ac.jp/index.php?TeX%A4%F2%CA%D8%CD%F8%A4%CB%BB%C8%A4%A6%A5%C4%A1%BC%A5%EB%CE%E0#le26dada)
- [pdf2svg](/pdf2svg/) ：PDF から SVG への変換
- [&rarr;画像ファイルのフォーマットを変換する： jpg png gif eps tiff ps bmp](http://www.henkan-muryo.com/image-converter.php)
