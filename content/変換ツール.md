## ビットマップ画像 (ラスターイメージ) ←→ EPS/PDF {#w1278ce9}

JPEG は EPS2（正確には PostScript Level 2 の EPS）にするとサイズがあまり増えません。

- [dktools](http://dktools.sourceforge.net/) ([CTAN:help/Catalogue/entries/dktools.html](https://mirror.ctan.org/help/Catalogue/entries/dktools.html))
    - bmeps (PNG 等 → EPS1, 2, 3/PDF．[W32TeX](/W32TeX/), [TeX Live](</TeX Live/>) にも収録されています)
- [sam2p](http://code.google.com/p/sam2p/)
    (sam2p foo.jpg foo.eps 等．[W32TeX](/W32TeX/), [TeX Live](</TeX Live/>) にも収録されています)

- [potrace](http://potrace.sourceforge.net/)
    (グレースケールbmp → EPS/PS/PDF/SVG．[W32TeX](/W32TeX/) にも収録されています)

- poppler
    - Linux では poppler-utils にコマンドが収録されています．
    - pdftocairo  - Portable Document Format (PDF) to PNG/JPEG/PDF/PS/EPS/SVG using cairo
- [ImageMagick](http://www.imagemagick.org/)
    - convert foo.jpg eps2:foo.eps とすると EPS2 になる ([MacTeX](/Mac/#f5466652) にも収録されています)
    - mogrify -format pdf \*.jpg とすると、フォルダ（ディレクトリ）内の全jpgをpdfに変換する（上書きされない）
- [jpeg2ps](http://www.pdflib.com/download/free-software/jpeg2ps/)
    (JPEG → EPS2/3)

- [EPS-conv](http://hp.vector.co.jp/authors/VA023018/epsconv.htm)
    (寺嶋 容明 さん)
    (Windows用, BMP/JPEG/PNG/GIF → EPS, Susie plug-in対応)
    - [TeXを便利に使うツール類#EPS-conv(画像変換ツール)](http://c.nagaokaut.ac.jp/index.php?TeX%A4%F2%CA%D8%CD%F8%A4%CB%BB%C8%A4%A6%A5%C4%A1%BC%A5%EB%CE%E0#le26dada)
- [png2eps](http://www.henlich.de/software/png2eps/)
    (png → (tiff) → eps変換をおこなうスクリプト)

- [imgtops/epstoimg](http://imgtops.sourceforge.net/)
    (旧 [imgtops2](http://gnuwin32.sourceforge.net/packages/imgtops2.htm))
    (要 [Python](http://www.python.org/) and [Python Imaging Library](http://www.pythonware.com/products/pil/)) (JPEG, PNG, GIF, Targa, BMP, etc. ←→ EPS)

- [Wjpeg2ps](http://www.vector.co.jp/soft/dl/win95/art/se248407.html) (JPEG → EPS)
- [EPS Viewer](http://epsviewer.org/) (EPS → JPEG, GIF, PNG)
