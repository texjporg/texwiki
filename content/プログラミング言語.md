### 処理系 {#z0aa88a3}

プログラミング初心者の方には C と Python と JavaScript をおすすめします．<br>
普段のプログラミングには Python を使用して C を使わないと書けないプログラムには C を使うといいと思います．<br>
ブラウザ, [TeXstudio](/TeXstudio/), [TeXworks](/TeXworks/) などでスクリプトを実行したい場合は JavaScript を使用してください．<br>
