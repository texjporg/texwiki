# 表記の哲学

## 表記の哲学 {#z0617861}

こだわり過ぎるのは如何なものかとは思いますが，
気にし始めると気になって仕方ないことも少なくないものです。

{{< children >}}

- 行列転置操作の ${}^{t} A$ や $A^{T}$ （イタリック体で良いかどうか？）
    - t/T は “<strong>t</strong>ranspose” の略なので，${}^{\mathrm{t}} A$ や
        $A^{\mathrm{T}}$ のように立てて書くべきだという流儀があります。
    - \top を使う人もいます。

- ISO に従うと，変数（と変関数）のシンボルだけをイタリック体（立体ではなくて）とするということのようです．
    - 例として $f(x)$ の $f$や$x$がイタリック体というわけです．
    - 物理定数は数学的には変数扱い（イタリック体）とのことです．（例：$c=299792458$）
