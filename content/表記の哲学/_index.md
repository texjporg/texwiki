# 表記の哲学

## 表記の哲学 {#z0617861}

こだわり過ぎるのは如何なものかとは思いますが，
気にし始めると気になって仕方ないことも少なくないものです。

{{< children >}}

- 行列転置操作の ${}^{t} A$ や $A^{T}$ （イタリック体で良いかどうか？）
    - t/T は “<strong>t</strong>ranspose” の略なので，${}^{\mathrm{t}} A$ や
        $A^{\mathrm{T}}$ のように立てて書くべきだという流儀があります。
    - \top を使う人もいます。

- 変数（と変関数）のシンボルをイタリック体　（ISO に従うとこれらだけを立体ではなくイタリック体とするということのようです．）
    - 例として $f(x)$ の $f$や$x$がイタリック体というわけです．
    - 物理定数は数学的には変数扱い（イタリック体）とのことです．（例：$c=299792458$）
    - これに対して数学的な定数と既定な関数の例は，$\sin \uppi$ ．

- BibTexデータの人名で，Jr か Jr. か？
    - どちらも間違いではないです．
    - 試しに BIBTEXing (Oren Patashnik, CTAN:biblio/bibtex/contrib/doc/btxdoc.pdf) を調べてみると，例の中では Jr でした．
    - 自分でbstファイルを書き置換を行うようにすれば，最終出力をどちらかに統一できそう．
