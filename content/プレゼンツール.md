## 数式画像作成ソフトウェア {#wc6f19a6}

- [Wikipedia.en:Formula editor](https://en.wikipedia.org/wiki/Formula%20editor) を参照．
- [TeXの数式をDTPソフトに](</TeXの数式をDTPソフトに/>) も参照
- Web アプリ
    - [TeXCrop](https://fukudat.net/texcrop/)
        …… 「PowerPoint でも，標準の数式エディタではなく TeX を用いて数式を書きたい．」という人のための Web アプリ 「日本語対応」
    - [TeXclip](https://texclip.marutank.net/)
        …… [PowerPoint](https://www.microsoft.com/ja-jp/microsoft-365/powerpoint)
        などに貼り付ける TeX の数式を生成する Web アプリ
    - [Equation Editor for online mathematics](https://editor.codecogs.com/)
        …… Web ベースの数式エディタ。SVG/GIF/PNG/PDF/EMF 形式の出力に対応。
    - [iTex2Img](https://www.sciweavers.org/free-online-latex-equation-editor)
        …… Web ベースの数式エディタ
    - [Tex Converter](https://atsushisakai.github.io/tex-tool/)
        …… Web ベースの数式エディタ
    - [LaTeX equation editor](https://www.numberempire.com/latexequationeditor.php)
        …… Web ベースの数式エディタ
    - [mathURL](https://mathurl.com/)
        …… Web ベースの数式エディタ
    - [数式画像作成ツール](https://hooktail.maxwell.jp/cgi-bin/mathimg.cgi)
        …… 物理のかぎプロジェクトによる数式作成。 Web アプリ
    - [数式画像生成 eqn2gif オンライン版](https://www.mech.tohoku-gakuin.ac.jp/rde/contents/library/ps2img/eqn2gif_online.html)
        …… LaTeX 形式の数式をかければ、簡単に数式画像が得られます。 Web アプリ
    - [Daum Equation Editor](https://chrome.google.com/webstore/detail/dinfmiceliiomokeofbocegmacmagjhe) Chrome Application
    - [TeX equation editor](https://chrome.google.com/webstore/detail/eggdddnmjoomglnkjhcpcnjbieiojini) Chrome Application

- スタンドアロンアプリ
    - [LaTeXの数式画像を作るならRaycastの「LaTeX to Image」が便利](https://qiita.com/masuipeo/items/8efc39031f3850750029)
    - [KLatexFormula](/KLatexFormula/)
        …… Qt ベースの数式エディタ．Windows/macOS/Linux で動作します．
    - [TeX2img](/TeX2img/)
        …… EPS/PDF/SVG/SVGZ/EMF/PNG/JPEG/TIFF/BMP/GIF 形式で出力可能。数式以外の地の文も画像化可能。日本語対応。
    - [libtexprintf &amp; utftex](https://github.com/bartp5/libtexprintf)
        …… 数式を ASCII アートで表現できる。
    - [ps2img](http://www.mech.tohoku-gakuin.ac.jp/rde/contents/library/ps2img/ps2img.html)
        …… EPS ファイルを GIF/PNG/BMP に適宜拡大縮小しつつ変換するツール。LaTeX の記述をダイレクトに画像ファイルにする機能もある。
    - [TEX THE WORLD](http://thewe.net/tex/) a Firefox add-on
    - [LaTeX It!](https://addons.mozilla.org/ja/thunderbird/addon/latex-it/) a Thunderbird add-on
    - [Blogger に LaTeX 数式を挿入するユーザースクリプト「LaTeX for Blogger with Google Chart API」](http://www.kuribo.info/2011/07/blogger-latex-latex-for-blogger-with.html)
    - [LaTeX Help](https://itunes.apple.com/jp/app/latex-help/id307772257?mt=8) iPhone, iPad 用 LaTeX 辞書

## その他のプレゼンツール {#od5dd4a8}

### プレゼンテーションソフト {#v14e3a37}

- [reveal.js](https://revealjs.com/)
    …… HTML PRESENTATIONS MADE EASY

- [Rabbit](https://rabbit-shocker.org/)
    …… プログラマ向け（主にRubyist向け）のプレゼンテーションツール。

- [Impressive](https://impressive.sourceforge.net/)
    …… PDF を用いたプレゼンソフト。ページ切り替えアニメーションや
    サムネイル表示，自動切り替え，講演時間表示などが可能。旧 KeyJnote。

- [JessyInk](/Inkscape/#k0206a78)
    …… [Inkscape](/Inkscape/) でスライドを作成するためのソフト．

- [Sozi](https://sozi.baierouge.fr/)
    …… SVG ドキュメントのためのプレゼンテーションツール．

- [WebSlide](https://www2.u-gakugei.ac.jp/~takizawa/WebSlide/)
    …… Web ブラウザによるプレゼンテーション ([qa:56260](https://okumuralab.org/~okumura/texfaq/qa/56260.html))

- [Magicpoint](http://member.wide.ad.jp/wg/mgp/)
    …… UNIX 由来の古典的なプレゼンソフト。LaTeX の数式を
    利用したり，mgp ファイルを LaTeX 形式に変換することが可能。
