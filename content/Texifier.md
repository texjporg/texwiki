# Texifier

## Texifier {#q728ac5b}

Texifier は macOS、iPadOS、iOSで動作する、高機能な(La)TeX統合環境です。

<strong>公式Webサイト</strong>

- [Texifier &middot; Smoothest way to write LaTeX](https://www.texifier.com/)

<strong>App Store</strong>

- [Texifier : LaTeX editor](https://apps.apple.com/jp/app/texifier-latex-editor/id550419159)

### 動作環境 {#m6120f50}

macOS, iPadOS, iOS

### 使い方（macOS版） {#b748650e}

- [Mac Tex環境の構築、リアルタイムTypeset機能をそなえたTexifierの設定も紹介](https://lifehack.world/mac-tex-texifier/)
- 左上のエンジン名（XeTeXなど）の右のつまみマークをクリックして、エンジンをpLaTeX,
    LuaLaTeXなどに切り替えられます。

### トラブルシューティング {#a42dd157}

- 多くの箇所の置換をするとフリーズしてしまう。
    - おおむね300か所以上に影響が及ぶ置換を試みるとフリーズするようです。他のエディタで置換するようにしましょう。
