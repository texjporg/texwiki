# Galley

## Galley {#o0963862}

Galley は macOS で動作する TeX/LaTeX 用の軽量な PDF プレビューアです。ファイルの自動更新と SyncTeX に対応しています。TeX/LaTeX の執筆者や組版を行う人のために作られており、不要なツールバーやステータスバーが無く、文書作成に集中できます。

- [GalleyPDF — Lightweight PDF Previewer for TeX/LaTeX](https://munepi.github.io/Galley/)
    - [Documentation | GalleyPDF](https://munepi.github.io/Galley/docs/)
- [GitHub - munepi/Galley: Galley — A lightweight macOS PDF previewer with SyncTeX support · GitHub](https://github.com/munepi/Galley)

### インストール {#x2cf4a1d}

- [https://github.com/munepi/Galley#installation](https://github.com/munepi/Galley#installation)

Homebrew を使用してインストールできます。

```
brew install --cask munepi/galley/galley
```

### 設定 {#t67b6e8b}

SyncTeX を使用して Visual Studio Code、Emacs、Vim/Neovim (VimTeX) 等と連携ができます。

- [https://github.com/munepi/Galley#configuration](https://github.com/munepi/Galley#configuration)
