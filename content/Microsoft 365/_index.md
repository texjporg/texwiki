### Microsoft 365 での LaTeX サポート {#v56856c9}

- [Microsoft 365 での LaTeX サポート | Microsoft Learn](https://learn.microsoft.com/ja-jp/office/math/latex)

Microsoft 365 アプリケーション (Word、Excel、PowerPoint) は、LaTeX 数式表記と Office Math Markup Language (OMML) の間で変換できます。

### Microsoft 365 での LaTeX mhchem サポート {#e6d1906d}

- [Microsoft 365 での LaTeX mhchem サポート | Microsoft Learn](https://learn.microsoft.com/ja-jp/office/math/latex.mhchem)

Word、Excel、PowerPointを含む Microsoft 365 アプリでは、[mhchem](/mhchem/) パッケージから LaTeX \ce{...} コマンドを使用して化学式と数式を作成できます。
