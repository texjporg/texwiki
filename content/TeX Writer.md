# TeX Writer

## TeX Writer {#ee6b4581}

TeX Writer は iOS, iPadOS, Android で動作する、高機能な(La)TeX統合環境です。

TeX Writer は日本語の文書をローカルでコンパイルできます。

TeX Writer の公式サイトで日本語用のテンプレートファイル [jp-template.tex](https://texwriter.net/templates?c=language&id=12) が配布されています。
