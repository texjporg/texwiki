## 表示 {#me73d63b}

### 文書構造 (アウトライン) の表示 {#y6d3450f}

\[表示(V)\]-\[文書構造面(U)\] とすると文書構造 (アウトライン) を表示できます．<br>

### LaTeX ソースの表示 {#s7174299}

\[表示(V)\]-\[ソース面(S)\] とすると LaTeX ソースを閲覧できます．<br>
LaTeX の他に LyXHTML, 平文, LyX 形式で表示することも可能です．<br>
デフォルトでは 現在の段落 になっています．<br>

形式(O): <span style="color:Black;background-color:#EEEEEE;">\[既定値　　　　　　　　　 ▼\]</span><br>
<span style="color:Black;background-color:#EEEEEE;">\[現在の段落　　　　　　　　　　　　▼\]</span><br>

<span style="color:#888888;background-color:White;">☐親文書観点で表示(M)</span><br>

☑自動更新<br>

リストから 全ソース を選択すると文書全体のソースコードを表示できます．<br>

形式(O): <span style="color:Black;background-color:#EEEEEE;">\[LaTeX (pLaTeX)　　　 ▼\]</span><br>
<span style="color:Black;background-color:#EEEEEE;">\[全ソース　　　　　　　　　　　　　　▼\]</span><br>

<span style="color:#888888;background-color:White;">☐親文書観点で表示(M)</span><br>

## 読み込み {#o63af929}

### LaTeX (plain) {#uce52cbb}

\[ファイル(F)\]-\[読み込み(I)\]-\[LaTeX (plain)...\]<br>

\[ツール(T)\]-\[設定(P)...\]-\[ファイル処理\]-\[変換子\] の [LaTeX (plain) -> LyX](</LyX/設定/#tcc5ab59>) の設定で

```
tex2lyx -e utf8 -f $$i $$o
```

のように utf8 を指定すれば日本語の TeX ファイルも読み込み可能です．<br>
TeX ファイルの文字コードが UTF-8 以外の場合は UTF-8 に変換してから読み込んでください．<br>

### XHTML ファイルの書き出し {#jb69a900}

\[ファイル(F)\]-\[書き出し(E)\]-\[LyXHTML\]

TeX ファイルを読み込んだあとで LyXHTML で書き出しを行うと LaTeX, YaTeX, TeXShop などの TeX を含んだ文字列が正しく出力されないようです．<br>
この場合は読み込む前にあらかじめ TeX ファイルの LaTeX, YaTeX, TeXShop などの文字列を \LaTeX{}, Ya\TeX{}, \TeX{}Shop などに変換しておいてから読み込むと LyXHTML で書き出しした場合でも TeX を含んだ文字列が正しく出力されるようです．<br>

- [LyXでのTeXファイルの読込みとXHTML書き出し](http://oku.edu.mie-u.ac.jp/tex/mod/forum/discuss.php?d=893)

## 編集 {#ne5d49e9}

### 言語 {#icf0ac1e}

部・章・節・小節・小々節・段落・小段落などで \[編集(E)\]-\[言語(L)\] が英語の場合，日本語をコピー &amp; ペーストすると \foreignlanguage\[japanese\]{...} が追加されます．<br>
babel を使用しない場合は，領域を選択して \[編集(E)\]-\[言語(L)\] を日本語にします．<br>
\[編集(E)\]-\[言語(L)\] は文書全体ではなく，選択領域の言語を指定するものです．<br>

## 画像 {#oc4e3c46}

画像は PDF, EPS, PNG, JPEG ファイルなどが使用できます．<br>

### dvipdfmx の場合 {#mc6e8440}

dvipdfmx で画像を使用する場合は，文書クラスのグラフィックドライバに DVIPDFMx を指定します．<br>
クラスオプションに dvipdfmx を設定した場合は 既定値 でも OK です．<br>
dvipdfmx の場合は PDF, EPS, PNG, JPEG ファイルが使用できます．<br>
PDF, PNG, JPEG ファイルは EPS ファイルに変換して処理されるようです．<br>

### dvips の場合 {#yf255c44}

dvips で画像を使用する場合は，文書クラスのグラフィックドライバに 既定値 または Dvips を指定します．<br>
dvips の場合は EPS ファイルが使用できます．<br>
dvips は PDF, PNG, JPEG ファイルに対応していませんが LyX が PDF, PNG, JPEG ファイルを自動的に EPS ファイルに変換して処理してくれるので PDF, EPS, PNG, JPEG ファイルが使用できます．<br>

### pdflatex, lualatex, luajitlatex の場合 {#maaa78b5}

pdflatex, lualatex, luajitlatex で画像を使用する場合は，文書クラスのグラフィックドライバに 既定値 または pdfTeX を指定します．<br>
pdflatex, lualatex, luajitlatex の場合は PDF, PNG, JPEG ファイルが使用できます．<br>
pdflatex, lualatex, luajitlatex は EPS ファイルに対応していませんが LyX が EPS ファイルを自動的に PDF ファイルに変換して処理してくれるので PDF, EPS, PNG, JPEG ファイルが使用できます．<br>

### xelatex の場合 {#ge85144d}

xelatex で画像を使用する場合は，文書クラスのグラフィックドライバに 既定値 または XeTeX を指定します．<br>
xelatex の場合は PDF, EPS, PNG, JPEG ファイルが使用できます．<br>
EPS ファイルは PDF ファイルに変換して処理されるようです．<br>

### EPS ファイルについて {#jf54d46f}

EPS ファイルは LyX で表示する際に表示可能な形式に変換するので表示できない場合があるかもしれません．<br>
表示できない場合は以下のようなメッセージが表示されます．<br>

```
読み込み可能な形式に変換するのに失敗しました
```

この場合でも LyX で PDF ファイルに変換して表示すれば表示されるので LyX で表示されなくても気にする必要はありません．<br>
どうしても LyX で表示したい場合は PDF ファイルに変換して使用してください．<br>
