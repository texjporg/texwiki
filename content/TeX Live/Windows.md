## インストール {#rc65f8ae}

ここではネットワークインストーラである install-tl-windows.exe / install-tl.zip を用いる方法と，全てのファイルが入っている ISO イメージをダウンロードする方法を説明します。

基本的には ネットワークインストーラ を用いる方法をおすすめします。
ネットワークインストーラで問題のある場合は ISO イメージ を用いる方法をご利用ください。 <!-- [[https://texwiki.texjp.org/?TeX%20Live]] と 公式ページの説明とおすすめするインストール方法を合わせます。 -->

### ネットワークインストーラの場合 {#w369638d}

[Installing TeX Live over the Internet](https://www.tug.org/texlive/acquire-netinstall.html) または [TeX Live](</TeX Live/#tlnet>) から install-tl-windows.exe または install-tl.zip のどちらかをダウンロードします。

- install-tl-windows.exe の場合はダウンロード後ダブルクリック（全ユーザにインストールする場合は右クリックから「管理者として実行(A)」を選ぶ）
- install-tl.zip の場合は展開後 install-tl-windows.bat をダブルクリック（全ユーザにインストールする場合は右クリックから「管理者として実行(A)」を選ぶ）

インストーラが起動します。
後は指示に従えば自動でインストールが行われます。

かなりの時間がかかります。
環境にもよりますが，多くの場合2時間から3時間ほどかかると思います。

以下は TeX Live 2025 の install-tl-windows.bat をダブルクリックして実行した例です。

#### テキストモードでのインストール {#f2f98067}

ターミナルから install-tl-windows.bat に -no-gui オプションをつけて実行することで、テキストモードでのインストールが可能となります。

> .\install-tl-windows.bat -no-gui

詳しい使い方は

### ISO イメージからのインストール {#zc468876}

[Acquiring TeX Live as an ISO image](http://www.tug.org/texlive/acquire-iso.html) または [TeX Live](</TeX Live/#iso>) から ISO イメージがダウンロードできます．
「download from a nearby CTAN mirror」から，texlive.iso をダウンロードしてください．
ダブルクリックすると DVD-ROM ドライブとしてマウントされます．
中には install-tl-windows.bat がありますので，後はネットワークインストールと同様の手順でインストールが可能です．
なお，ISO イメージの更新頻度は1年に1度のため，インストールが完了した直後に後述するアップデートを行うことをおすすめします．
ISO イメージが作成された当時に未解決であったバグや不具合が解決されていることがあります．

## アップデート {#a6223106}

\[スタート\] &gt; \[すべて\] &gt; \[TeX Live 2025\] &gt; \[TLShell TeX Live Manager\] を選択して TeX Live Shell を起動することで，パッケージをアップデートすることが可能です。

\[ファイル\] &gt; \[リポジトリを読み込む\] を選択して \[すべてアップデート\] をクリックすれば更新されます。

「tlmgrは最新版？　最新の状態です」と表示されていない場合は \[tlmgrをアップデート\] をクリックして tlmgr を最新の状態にしてから \[すべてアップデート\] をクリックして更新します。

場合によっては（特にインストール直後などは）かなり時間がかかることがあります。

ターミナルから

```
tlmgr update --self --all
```

でも行えます．

ただし，アップデートによってパッケージや設定が変更されて，今まで動いていたものが動かなくなったりすることがあるかもしれません。

- C:\texlive\2025\tlpkg\backups

にパッケージのバックアップが保存されます。
アップデートによって動作しなくなった場合は以前のバージョンに戻してください。

- アップデートが失敗した場合は以下の例のように再度アップデートできます。

    ```
    tlmgr update --reinstall-forcibly-removed --all --repository https://ftp.jaist.ac.jp/pub/CTAN/systems/texlive/tlnet/
    ```

パッケージは

- [tlmgr](/tlmgr/) (コマンドライン)
- [TeX Live Shell (GUI 版 TeX Live Manager)](</TeX Live Shell/>) (GUI)

で管理できます。

### プロキシ認証が必要な場合 {#a1f81a23}

- プロキシ認証がうまくいかなくてアップデートできない場合、
    あるいは、アップデートに時間がかかりすぎると感じたら、
    環境変数でプロキシ設定を試すと良いかも。

    ```
    setx http_proxy http://USER:PASSWORD@example.com:8080
    setx https_proxy http://USER:PASSWORD@example.com:8080
    ```

- 上記でダメなら--no-persistent-downloads のオプションが効果あるかもしれません。

    ```
    tlmgr update --self --all --no-persistent-downloads
    ```

- 環境変数でダウンローダー指定する手も

    ```
    setx TEXLIVE_DOWNLOADER wget
    ```

    C:\texlive\2025\tlpkg\installer\wget\\.wgetrc のファイルに以下のような内容で保存しておく。

    ```
    http_proxy=http://USER:PASSWORD@example.com:8080
    ftp_proxy=http://USER:PASSWORD@example.com:8080
    use_proxy = on
    ```
