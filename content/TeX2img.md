# TeX2img

## TeX2img {#ac311792}

<span style="color:White;background-color:#5F2F2F;">　　<strong>◆CONTENTS◆</strong>　　</span><br>

## TeX2img とは {#icba8205}

TeX2img は TeX ソースコードを画像に変換するアプリケーションです．<br>

- [TeX2img](http://www.math.sci.hokudai.ac.jp/~abenori/soft/#TEX2IMG) (Windows 版)
- [TeX2img](http://island.geocities.jp/loveinequality/) (Mac 版)

### 動作環境 {#tf19749b}

Windows, OS X

### License {#a8c9cce2}

#### Windows 版 {#t3c9d1be}

[BSD 2-Clause](https://github.com/abenori/TeX2img/blob/master/license.txt)

#### Mac 版 {#nc589b01}

GPLv2

### 出力形式 {#n63a1aac}

入力した TeX ソースコードを TeX でコンパイルして，次のような形式の画像で出力します．<br>

- アウトラインをとった EPS ファイル
- JPEG ファイル
- PNG ファイル
- 背景を透過させた PNG ファイル
- PDF ファイル
