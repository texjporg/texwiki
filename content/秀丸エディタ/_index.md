## 標準のエンコードの種類 {#m676962a}

秀丸エディタの標準のエンコードの種類はデフォルトでは日本語(Shift-JIS)です．<br>
エンコードの種類を UTF-8 にする場合は Unicode(UTF-8) を選択します．<br>

***

　　　☑ファイルの内容を解析してエンコードの種類を自動認識する(E)<br>
　　　　　☑Unicode(UTF-8)<br>
　　　　　☑日本語(Shift-JIS)<br>
　　　　　☑日本語(EUC)<br>

　　　　　　<span style="color:#3333CC;">◎</span>最初に確定したものにする<br>
　　　　　　◯優先順位に従う（２回読み込みが働くことがあります）<br>
　　　　　　◯候補の一覧を表示<br>
　　　☑XML宣言の認識(X)　　　　　　　　　　<span style="color:Black;background-color:#EEEEEE;">\[　標準のエンコードの種類(D)...　\]</span><br>
　　　☑HTMLのmetaタグを認識(H)<br>
　　　☑UnicodeのBOMを認識(B)<br>

***

<span style="color:Black;background-color:#8080FF;"><ins>　<span style="color:White;"><strong>標準のエンコードの種類</strong></span>　　　　　　　　　　　　　　　　　　　　　　　　　　　　　<span style="color:Black;background-color:#CC3333;"></ins>\[ 　<strong><span style="color:White;">✕</span></strong>　 \]<ins></span> </ins></span><br>

　　　標準のエンコードの種類(D)<br>
　　　　エンコードの種類(C) :　<span style="color:Black;background-color:#EEEEEE;">\[Unicode(UTF-8)　　　　　　　　　　　　　　▼\]</span><br>
　　　　改行コード(R) :　　　　　<span style="color:Black;background-color:#EEEEEE;">\[自動　　　　　　　　　▼\]</span><br>
　　　　BOMの有無 :　　　　　　<span style="color:Black;background-color:#EEEEEE;">\[自動　　　　　　　　　▼\]</span><br>
　　　標準のエンコードの種類は、自動判定できなかった場合と、新規作成時<br>
　　　とASCIIのファイルに適用されます。<br>

### pdfpLaTeX.mac {#h4eb5579}

***

```
call main;
endmacro;

main:
  ##fso = createobject("Scripting.FileSystemObject");
  $$c = callmethod_returnstr(##fso, "GetParentFolderName", filename2);
  $$b = callmethod_returnstr(##fso, "GetBaseName", filename2);
  $$cd = "cd /d " + "\"" + $$c + "\"";
  $$latex = "platex -synctex=1 -guess-input-enc -sjis-terminal";
  if ((charset & 0x3F) == 6) {
    $$latex = "platex -synctex=1 -no-guess-input-enc -kanji=utf8 -sjis-terminal";
  } else if ((charset & 0x3F) == 1) {
    $$latex = "platex -synctex=1 -no-guess-input-enc -kanji=sjis -sjis-terminal";
  } else if ((charset & 0x3F) == 3) {
    $$latex = "platex -synctex=1 -no-guess-input-enc -kanji=euc -sjis-terminal";
  } else if ((charset & 0x3F) == 4) {
    $$latex = "platex -synctex=1 -no-guess-input-enc -kanji=jis -sjis-terminal";
  }
  $$latex = $$latex + " " + "-jobname=" + "\"" + $$b + "\"" + " " + "\"" + $$b + "\"";
  $$dvipdfm = "dvipdfmx" + " " + "\"" + $$b + "\"";
  $$cmd = "cmd /c " + $$cd + " && " + $$latex + " && " + $$dvipdfm;

  question $$cmd;
  if (result == yes) {
    save;
    ##shell = createobject("WScript.Shell");
    callmethod ##shell, "Run", $$cmd;
    releaseobject ##shell;
  }

  releaseobject ##fso;
```

### TeXworks.mac {#r100b824}

[TeXworks#組み込みの PDF ビューアに日本語を表示させる](/TeXworks/#t5313ebc) を参照してフォントの埋め込みの設定を行います．<br>

***

```
call main;
endmacro;

main:
  ##fso = createobject("Scripting.FileSystemObject");
  ##re = createobject("VBScript.RegExp");
  $$currentTeXFile = filename2;
  setpropstr ##re, "Pattern", "\.[^.]*$";
  $$pdfFile = callmethod_returnstr(##re, "Replace", $$currentTeXFile, ".pdf");
  $$texworks = "texworks";

  if (!existfile($$pdfFile)) {
    $$mainTeXFile = input("Input the path to main TeX file.", callmethod_returnstr(##re, "Replace", $$pdfFile, ".tex"));
    if ($$mainTeXFile != "") {
      $$pdfFile = callmethod_returnstr(##re, "Replace", $$mainTeXFile, ".pdf");
    }
  }

  $$mainTeXDir = callmethod_returnstr(##fso, "GetParentFolderName", $$pdfFile);
  $$cd = "cd /d " + "\"" + $$mainTeXDir + "\"";
  $$pdfFile = "\"" + $$pdfFile + "\"";

  $$args = $$texworks + " " + $$pdfFile;
  $$cmd = "cmd /c " + $$cd + " && echo " + $$args + " | cmd";
  ##shell = createobject("WScript.Shell");
  callmethod ##shell, "Run", $$cmd;

  releaseobject ##shell;
  releaseobject ##re;
  releaseobject ##fso;
```
