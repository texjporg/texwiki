# Texmaker/インストール

[Texmaker](/Texmaker/) > インストール

***

***

## ダウンロード/インストール {#q69dea61}

[Texmaker (free cross-platform latex editor)](http://www.xm1math.net/texmaker/download.html)
から，Windows, OS X, Linux 用のバイナリおよびソースコードがダウンロードできます．<br>
Texmaker 日本語化キット
から，Texmaker の日本語化キットがダウンロードできます．<br>

### [Texmaker for Windows](http://www.xm1math.net/texmaker/download.html#windows) {#a1196a5e}

exe ファイルの場合は，texmakerwin32_install.exe をダウンロードして実行すればインストールできます．<br>
Portable バージョンの場合は，texmakerwin32usb.zip をダウンロードして展開するだけで OK です．<br>

- [Texmaker/設定/Windows](</Texmaker/設定/Windows/>)

を参照して設定します．<br>

### [Texmaker for OS X](http://www.xm1math.net/texmaker/download.html#macosx) {#d8391431}

OS X 向けのバイナリが用意されています．

- Texmaker/設定/OS X

を参照して設定します．<br>

### [Texmaker for Linux](http://www.xm1math.net/texmaker/download.html#linux) {#u2f1821c}

- DEB パッケージ
- RPM パッケージ

が用意されています．

- [Texmaker/設定/Linux](</Texmaker/設定/Linux/>)

を参照して設定します．<br>

#### Arch Linux {#wc1ba0bb}

- ArchLinuxPackageSearch.name:texmaker

```
sudo pacman -S texmaker
```

#### Linux Mint/Debian/Ubuntu {#hd6a5068}

- UbuntuPackageSearch:texmaker, UbuntuPackageSearch.en:texmaker, UbuntuPackageSearch.ja:texmaker
- DebianPackageSearch:texmaker, DebianPackageSearch.ja:texmaker, DebianPackageSearch.ja:texmaker

```
sudo apt install texmaker
```

#### Fedora {#pb4caa16}

- [https://apps.fedoraproject.org/packages/texmaker](https://apps.fedoraproject.org/packages/texmaker)

```
sudo dnf install texmaker
```

#### openSUSE {#xc3933ef}

- [https://software.opensuse.org/package/texmaker](https://software.opensuse.org/package/texmaker)

```
sudo zypper install texmaker
```
