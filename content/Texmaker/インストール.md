### [Texmaker for Windows](http://www.xm1math.net/texmaker/download.html#windows) {#a1196a5e}

Windows 7, Vista, XP で動作します．<br>
exe ファイルの場合は，texmakerwin32_install.exe をダウンロードして実行すればインストールできます．<br>
Portable バージョンの場合は，texmakerwin32usb.zip をダウンロードして展開するだけで OK です．<br>

- [設定](/Texmaker/#e3cd1932)

を参考にして設定を行います．

- [texmaker-3.5(Win)修正版](http://blogs.yahoo.co.jp/igproj_fusion/15979041.html)

から日本語入力の問題を修正した Windows バイナリがダウンロードできます．<br>
この exe ファイルは 7-Zip でも展開することが可能です．<br>

### [Texmaker for OS X](http://www.xm1math.net/texmaker/download.html#macosx) {#d8391431}

[OS X の Texmaker で，文字コードが UTF-8 の場合に Backslash (U+005C) が入力できず 円記号 (U+00A5) になってしまう](/Texmaker/#u2a90df7)ようです．<br>
[KeyRemap4MacBook](http://pqrs.org/macosx/keyremap4macbook/index.html.ja) で Backslash が優先されるようにキーバインドを変更するといいようです．<br>
