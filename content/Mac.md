MacTeX は [TeX Live](</TeX Live/>) をベースにした OS X 専用の TeX ディストリビューションです．<br>
MacTeX, [TeX Live](</TeX Live/>) はサイズが大きいのでミラーサイトを利用してください．<br>
TUG から直接ダウンロードするよりもミラーサイトを利用したほうが早くダウンロードできます．<br>
<span style="color:black;background-color:yellow;"><strong>Google Chrome, Mozilla Firefox で MacTeX をダウンロードしてインストールできない場合は Safari でダウンロードしてください．</strong></span><br>

> 奥村先生の[［改訂第6版］LaTeX2e美文書作成入門](http://oku.edu.mie-u.ac.jp/~okumura/bibun6/)には TeX Live 2013 が収録されています．<br>
> インストールディレクトリなどは変更されており、インターネットから直接インストールする MacTeX, TeX Live とは異なっています．<br>

### MacTeX インストールの概略 {#t244993f}

1. [MacTeX のホームページ](http://tug.org/mactex/)または上記の各ミラーサイトから MacTeX.pkg をダウンロードします。<br>
    - 「本家」の MacTeX からのダウンロードも、自動的に CTAN のミラーサイトからのダウンロードとなります。
    - MacTeXtras.zip は、追加のフロントエンドなどが収録されています。必須ではありません。（→[MacTeXtrasの説明](http://tug.org/mactex/mactextras.html)）
1. ダウンロードした MacTeX.pkg をダブルクリックしてインストールします。
    - <strong>手動でパスを通す必要はありません</strong>。（→[What is Installed.pdf を参照](http://tug.org/mactex/What_Is_Installed.pdf)）<br>PATH、MANPATH はインストール時に適切に自動設定されます。<br>
        ターミナルで以下のコマンドを実行し、返ってきた PATH に <strong>/usr/texbin</strong> が含まれていれば大丈夫です。

        ```
        $ echo $PATH
        ```

        - <strong>ターミナル初心者への注意：</strong> 上記コマンドの先頭の <strong>$</strong> はターミナルを起動すると示される「コマンド入力待ちの記号（プロンプト）」を表します。従って、実際に入力するのは echo $PATH です。
        - [Ghostscript.app - マスクメロン](http://www.muskmelon.jp/?page_id=75)からインストールした場合など、別途 Ghostscript をインストールして使用する場合は、そのために改めてパスを通す必要があるかもしれません。
        - 以前に MacPorts または Fink からインストールした TeX が残っている場合は、パスの優先順位の再設定が必要です。（→[Multiple TeX Distributions](http://tug.org/mactex/multipletexdistributions.html)）
1. ターミナル上で sudo tlmgr update --self --all または tlmgr の GUI アプリケーションである TeX Live Utility を用いて最新版までアップデートします。（→[tlmgr を使用してのアップデート](/Mac/#p3c663c9)）
1. MacTeX-2014 の場合は texmf.cnf を編集して、利便性を高める設定をします。 (→[texmf.cnf への extractbb などの追加](/Mac/#h357d047))
    - texmf.cnf の shell_escape_commands のリストに extractbb を加えることで、dvipdfmx 用の Bounding Box を作成するコマンド extractbb の実行を自動化できます。
1. 日本語環境を整えます。
    - ヒラギノフォントを TeX でも利用可能にします。（→[日本語環境の整備](/Mac/#i9febc9b)）
        - 以前の TeX Live で既に設定済みの場合は、この手順は不要です。
        - この設定をしなくても日本語は使用できますし、IPAexフォント/IPAフォントを埋め込んだPDFの作成もできますが、高品質なフォントであるヒラギノが使える OS X ならばヒラギノを利用可能にする設定は有用でしょう。
    - updmap-sys をターミナル上で実行し、利用するフォントの設定を行います。
        - kanji-config-updmap-sys を利用するのが簡便です。ともに、sudo として実行します。
1. 必要に応じて、付属ソフトの設定やアップデートを行います。
    - [LyX](/LyX/), [TeXstudio](/TeXstudio/), [Texmaker](/Texmaker/), [TeXworks](/TeXworks/), TexitEasy, [TeXShop](/TeXShop/), TeXnicle などのソフトを用いる場合は、それぞれのソフトに対し適切な設定が必要です。
1. <strong>Happy LaTeXing!</strong>

MacTeX-2014 には以下のパッケージが収録されています．

- TeXLive-2014

> TeX Live 本体です。<br>

- GUI-Applications

> インストールすることでアプリケーションフォルダに TeX フォルダが作成されます．<br>
> READ ME FIRST.pdf、What Is Installed.pdf、Eps-Tiff-Conversion.pdf などの書類もインストールされます．<br>
> GUI Applications には以下のアプリケーションが収録されています．<br>
> アプリケーションフォルダの中の TeX フォルダに収められています．<br>
>
> - [BibDesk](http://bibdesk.sourceforge.net/)

> 文献管理ソフト

- [Excalibur](http://excalibur.sourceforge.net/)

> TeX に対応したスペルチェッカー

- [LaTeXiT](/LaTeXiT/)

> 単独の数式を作成して他のアプリケーションにコピペするのに便利なソフトウェア<br>
> 設定は [LaTeXiT#環境設定](/LaTeXiT/#tab3d738) を参照してください．<br>

- [TeX Live Utility](</TeX Live Utility/>)

> tlmgr（TeX Live Manager）の OS X ネイティブの GUI アプリケーション。<br>
> 最初の起動時に、最新版へのアップデートを促されます。<br>
> 複数のリポジトリを並行管理できます。<br>

- [TeXShop](/TeXShop/)

> OS X 専用の TeX 統合環境．<br>

### tlmgr を使用してのアップデート {#p3c663c9}

### texmf.cnf への extractbb などの追加 {#h357d047}

MacTeX-2014, TeX Live 2014 の場合は利便性を高めるため、コンパイル時の自動実行を許可するコマンドを texmf.cnf に追加設定します．

注意
: &nbsp;

: 無制限にコマンドを追加すると<strong>セキュリティ上、危険なことがあります</strong>。~

悪意ある実行ファイルを自動実行させることがないよう、下に示したもの以外を追加する場合は慎重の上にも慎重を期す必要があります．<br>

たとえば texmf.cnf に extractbb を書き加えておくと、コンパイル時に自動実行されるようになりますので画像を含んだソースファイルをコンパイルするために「事前に extractbb を実行する」という作業が必要なくなります．<br>
tlmgr を使用してアップデートすると [/usr/local/texlive/2014/texmf-dist/web2c/texmf.cnf](http://www.tug.org/svn/texlive/trunk/Master/texmf-dist/web2c/texmf.cnf?view=markup) が上書きされる可能性があるのでオリジナルの texmf.cnf を直接編集するのではなく、TEXMFLOCAL の texmf.cnf に設定を記入します。<br>
TEXMFLOCAL の値を確認します．<br>

```
$ kpsewhich -var-value TEXMFLOCAL
/usr/local/texlive/texmf-local
```

Mac に付属するテキストエディットで作成するとエラーとなりえますので、ターミナル上のエディタを使用するのが無難です．<br>
以下では nano を使って編集しています．（texmf.cnf が存在しない場合は自動的に新規作成されます．）<br>

```
$ nano /usr/local/texlive/texmf-local/web2c/texmf.cnf 
```

として、以下を書き込み、保存（WriteOut）します．（保存できない場合は、いったん Exit して、改めて sudo nano として実行してください．）<br>

```
shell_escape_commands = \
bibtex,bibtex8,bibtexu,upbibtex,biber,\
kpsewhich,\
makeindex,mendex,texindy,xindy,\
mpost,upmpost,\
repstopdf,epspdf,extractbb
```

mktexlsr を実行します．<br>

```
$ sudo mktexlsr
```

#### ヒラギノフォント {#d19a1537}

- ヒラギノフォントを利用可能にする設定
    - [［改訂第6版］LaTeX2e美文書作成入門](http://oku.edu.mie-u.ac.jp/~okumura/bibun6/)では既に設定済みです。<br>
    - MacTeX インストールの初期設定のままでは、TeXでヒラギノフォントを用いることはできません。<br>
        ターミナル上で、ヒラギノフォントのシンボリックリンクを作成し、TeX で利用できるようにします。<br>
        [日本語フォントのセットアップ](http://www.fugenji.org/~thomas/texlive-guide/font_setup.html)にも詳細な記述があります。<br>

        ```
        $ sudo mkdir -p /usr/local/texlive/texmf-local/fonts/opentype/hiragino/
        $ cd /usr/local/texlive/texmf-local/fonts/opentype/hiragino/
        $ sudo ln -fs "/Library/Fonts/ヒラギノ明朝 Pro W3.otf" ./HiraMinPro-W3.otf
        $ sudo ln -fs "/Library/Fonts/ヒラギノ明朝 Pro W6.otf" ./HiraMinPro-W6.otf
        $ sudo ln -fs "/Library/Fonts/ヒラギノ丸ゴ Pro W4.otf" ./HiraMaruPro-W4.otf
        $ sudo ln -fs "/Library/Fonts/ヒラギノ角ゴ Pro W3.otf" ./HiraKakuPro-W3.otf
        $ sudo ln -fs "/Library/Fonts/ヒラギノ角ゴ Pro W6.otf" ./HiraKakuPro-W6.otf
        $ sudo ln -fs "/Library/Fonts/ヒラギノ角ゴ Std W8.otf" ./HiraKakuStd-W8.otf
        $ sudo mktexlsr
        ```

    - ヒラギノのNシリーズ（[JIS X 0213:2004](http://ja.wikipedia.org/wiki/JIS_X_0213)に対応した字形）を利用する場合（upLaTeX では \usepackage\[uplatex,jis2004\]{otf} とすれば使えます。）<br>

        ```
        $ sudo mkdir -p /usr/local/texlive/texmf-local/fonts/opentype/hiragino/
        $ cd /usr/local/texlive/texmf-local/fonts/opentype/hiragino/
        $ sudo ln -fs "/System/Library/Fonts/ヒラギノ明朝 ProN W3.otf" ./HiraMinProN-W3.otf
        $ sudo ln -fs "/System/Library/Fonts/ヒラギノ明朝 ProN W6.otf" ./HiraMinProN-W6.otf
        $ sudo ln -fs "/Library/Fonts/ヒラギノ丸ゴ ProN W4.otf" ./HiraMaruProN-W4.otf
        $ sudo ln -fs "/System/Library/Fonts/ヒラギノ角ゴ ProN W3.otf" ./HiraKakuProN-W3.otf
        $ sudo ln -fs "/System/Library/Fonts/ヒラギノ角ゴ ProN W6.otf" ./HiraKakuProN-W6.otf
        $ sudo ln -fs "/Library/Fonts/ヒラギノ角ゴ StdN W8.otf" ./HiraKakuStdN-W8.otf
        $ sudo mktexlsr
        ```

- ヒラギノフォントをPDFなどに埋め込む設定とする場合は、ターミナル上で以下を実行します。<br>

    ```
    $ sudo updmap-sys --setoption kanjiEmbed hiragino　（ヒラギノフォントを埋め込む）
    ```

    - ヒラギノ以外のフォントを埋め込む設定にする際には、ターミナル上で以下を実行します。（[OTF](/OTF/)も参照）<br>

        ```
        $ sudo updmap-sys --setoption kanjiEmbed noEmbed  （埋め込まない）*初期設定値*
        $ sudo updmap-sys --setoption kanjiEmbed ipaex    （IPAexフォントを埋め込む）
        $ sudo updmap-sys --setoption kanjiEmbed ipa      （IPAフォントを埋め込む）
        $ sudo updmap-sys --setoption kanjiEmbed ms       （MSフォントを埋め込む）
        $ sudo updmap-sys --setoption kanjiEmbed yu-win   （游フォントを埋め込む）
        $ sudo updmap-sys --setoption kanjiEmbed yu-osx   （游フォントを埋め込む）
        $ sudo updmap-sys --setoption kanjiEmbed kozuka   （小塚書体を埋め込む）
        $ sudo updmap-sys --setoption kanjiEmbed morisawa （モリサワフォントを埋め込む）
        ```

#### updmap(-sys) の使用に関する注意点 {#qdce07c2}

- <strong>注意</strong> updmap-sys ではなく updmap を使用した場合は ユーザー個別の texmf（TEXMFHOME）に設定が書き込まれ、その個別設定の方が updmap-sys によるシステム全体の設定よりも優先されます。<br>
    tlmgr は updmap-sys を内部で呼びだしますが、後述の kanji-config-updmap は -sys なしで使用すると updmap を内部で呼びだして実行します。<br>
    <strong>-sys をつけたコマンドによる新しい設定が反映されない場合は、-sys なしの updmap による設定が TEXMFHOME に残ってないか確認してください</strong>。（-sys なしの updmap による設定は不可視ファイルとなっています。）

- updmap-sys は TEXMFLOCAL を検索対象とはしますが、TEXMFHOME は検索しませんので、フォントは原則として TEXMFLOCAL に置くことが推奨されています。(→ [About Shell Escape and Installing Fonts in 2012, 2013 and 2014](http://tug.org/mactex/TeXLive2012+Changes.pdf) を参照)<br>
    TEXMFHOME にフォントを置く場合は、updmap（-sys なし）を実行する必要があります。<br>
    - 埋め込むフォントを細かく制御したい場合は、手動で map ファイルを書き換えます。

#### kanji-config-updmap(-sys) {#hf34afcc}

- [kanji-config-updmap](https://gitorious.org/tlptexlive/jfontmaps/source/script/kanji-config-updmap.pl) を使用すれば PDFへの埋め込みフォントの指定、および埋め込み状況の確認ができます。<br>
    ターミナル上で実行します。<br>
    新規インストール直後など、kanji-config-updmap-sys で設定してもPDFへの埋め込みがされない場合は、上の updmap-sys を使う方法を試してください。<br>

    ```
    $ sudo kanji-config-updmap-sys <fontname>  （otf-<fontname>.map にしたがってフォントを埋め込む）
    $ sudo kanji-config-updmap-sys auto        （自動的に <fontname> のいずれかを埋め込む）
    $ sudo kanji-config-updmap-sys nofont      （PDF にフォントを埋め込まない）
    $ sudo kanji-config-updmap-sys status      （現在の埋め込み設定を確認する）
    ```

    - 自動的に埋め込み設定されるフォント &lt;fontname> は次のものです．<br>

        ```
        hiragino, hiragino-pron, morisawa, morisawa-pr6n, kozuka, kozuka-pr6, kozuka-pr6n, ipaex, ipa, ms, yu-win, yu-osx
        （いずれもないときは nofont になります） 
        ```

    - オプションとして -jis2004 を指定すると、JIS2004字形を使用する設定となります。<br>
    - kanji-config-updmap-sys は内部で updmap-sys を呼び出しますので、設定はシステムレベルで共通の設定として保存されます。<br>
        ユーザー個別の設定としてフォントを指定したいときは、kanji-config-updmap を使用します。
    - upLaTeX + dvipdfmx を実行する場合は ptex2pdf が便利です．<br>

        ```
        $ ptex2pdf -u -l -ot '-synctex=1' -od '-f uptex-hiragino-pron-04.map' hoge.tex
        ```

## パッケージ管理システムによるインストール {#e3decd1a}

### [Homebrew](http://brew.sh/) {#za78e055}

- [https://github.com/caskroom/homebrew-cask/blob/master/Casks/mactex.rb](https://github.com/caskroom/homebrew-cask/blob/master/Casks/mactex.rb)
- [https://github.com/caskroom/homebrew-cask/blob/master/Casks/basictex.rb](https://github.com/caskroom/homebrew-cask/blob/master/Casks/basictex.rb)

#### MacTeX {#m895e66c}

TeX Live をフルインストールする場合は MacTeX をインストールしてください．<br>
Homebrew で MacTeX をインストールできます．<br>
Ghostscript などのツールも Homebrew でインストールできます．<br>

```
$ brew install caskroom/cask/brew-cask
$ brew cask install mactex
$ export PATH=/usr/texbin:$PATH
$ sudo tlmgr update --self --all
```

#### BasicTeX {#t6edeb9b}

TeX Live をフルインストールしたくない場合は TeX Live のサブセットである BasicTeX をインストールします．<br>

```
$ brew install caskroom/cask/brew-cask
$ brew cask install basictex
$ export PATH=/usr/texbin:$PATH
$ sudo tlmgr update --self --all
$ sudo tlmgr install collection-langjapanese
```

## [統合環境・エディタ](</TeX用エディタ/>) {#i31113c1}

LaTeX での文書作成を支援するための統合環境・エディタが開発されています．<br>
初心者の方はまずは LaTeX 用の統合環境を使用して LaTeX に慣れるのがいいとおもいます．<br>
エディタ・マクロ・プラグインの種類によって得手不得手があったり不具合が発生したりする場合があります．<br>
問題が発生した場合は別のエディタを使用してください．<br>
人によってエディタの好みは様々なので自分にあったエディタを見つけてください．<br>
見つからない人は自作してみるのもいいかもしれません．<br>

- [Wikipedia:Comparison_of_TeX_editors](https://www.wikipedia.org/wiki/Comparison_of_TeX_editors)
- [LaTeX Editors/IDEs](http://tex.stackexchange.com/questions/339/latex-editors-ides)

にも Mac で使用可能な LaTeX 用の統合環境・エディタが紹介されています．
