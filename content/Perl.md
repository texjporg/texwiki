### インストール {#l06514b7}

#### Windows {#bfff8462}

- [Strawberry Perl](http://strawberryperl.com/)

Strawberry Perl を C:\strawberry にインストールした場合は

```
;C:\strawberry\c\bin;C:\strawberry\perl\site\bin;C:\strawberry\perl\bin
```

がシステム環境変数 Path に追加されます．
