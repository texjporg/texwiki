## Adobe Reader とは {#t103678c}

Adobe Reader は PDF ファイルを表示・印刷するためのソフトウェアです．

Adobe Reader の Windows 版は PDF ファイルをロックしてしまうので，PDF ファイルのプレビューには向いていません．<br>
PDF ファイルのプレビューには [SumatraPDF](/SumatraPDF/), [TeXworks](/TeXworks/), [TeXstudio](/TeXstudio/) を使用して，最終確認や印刷をする場合に Adobe Reader を使用することをおすすめします．<br>

## Adobe Reader をコマンドラインから操作する方法 (Windows) {#f9d733e4}

TeX Live, W32TeX に含まれている pdfopen を使用して PDF ファイルを Adobe Reader で開くことができます．<br>
pdfopen を使用する場合 PDF ファイルは Adobe Reader に関連付けしておく必要があります．<br>

### PDF ファイルを開く {#id6d0918}

```
pdfopen --rxi --file hoge.pdf
```

または

```
echo open hoge.pdf | pdfdde --rxi
```

### PDF ファイルを閉じる {#h619779d}

```
pdfopen --rxi --file hoge.pdf && pdfclose --rxi --file hoge.pdf
```

または

```
echo open hoge.pdf | pdfdde --rxi && echo close hoge.pdf | pdfdde --rxi
```

### Adobe Reader を終了する {#pb5aeda1}

```
echo exit | pdfdde --rxi
```

### 指定したページを表示する {#lc08871d}

- [DDEを用いてページを指定してPDFを表示する](http://kb2.adobe.com/jp/cps/510/510047.html)
- [Adobe Readerで指定したファイルの指定したページを開く](http://owlsperspective.blogspot.jp/2008/07/acroview.html)
- [http://stackoverflow.com/questions/619158/adobe-reader-command-line-reference](http://stackoverflow.com/questions/619158/adobe-reader-command-line-reference)
- [http://partners.adobe.com/public/developer/en/acrobat/PDFOpenParameters.pdf#page=5](http://partners.adobe.com/public/developer/en/acrobat/PDFOpenParameters.pdf#page=5)
- [http://kb2.adobe.com/jp/cps/511/511759/attachments/511759_pdf_open_parameters.pdf](http://kb2.adobe.com/jp/cps/511/511759/attachments/511759_pdf_open_parameters.pdf)

3ページ目を表示するには以下のようにします．

```
start AcroRd32 /a "page=3" hoge.pdf
```

または

```
pdfopen --rxi --file hoge.pdf --page 3
```

または

```
echo open hoge.pdf | pdfdde --rxi && echo goto hoge.pdf 3 | pdfdde --rxi
```

## SyncTeX {#s533a23f}

Adobe Reader は [SyncTeX](/SyncTeX/) には対応していませんが synctex コマンドを使用して forward and inverse search を行うことができます．

### forward search {#s30ae8a0}

TeX ファイルの 30 行目に対応する PDF ファイルの該当するページにジャンプしたい場合は

```
synctex view -i "30:0:hoge.tex" -o "hoge.pdf" -x "pdfopen --rxi --file '%{output}' --page %{page+1}"
synctex view -i "30:0:hoge.tex" -o "hoge.pdf" -x "'C:\Program Files (x86)\Adobe\Reader 11.0\Reader\AcroRd32.exe' /a 'page=%{page+1}' '%{output}'"
synctex view -i "30:0:hoge.tex" -o "hoge.pdf" -x "'C:\Program Files\Adobe\Reader 11.0\Reader\AcroRd32.exe' /a 'page=%{page+1}' '%{output}'"
```

のように実行します．

詳細については

```
synctex help view
```

を参照してください．

### inverse search {#f99c6c1f}

[TeXstudio](/TeXstudio/) で PDF ファイルの 30 ページ目の x 座標 0, y 座標 0 に対応する TeX ファイルの該当する行にジャンプしたい場合は

```
synctex edit -o "30:0:0:hoge.pdf" -x "texstudio -line %{line} '%{input}'"
```

のように実行します．

詳細については

```
synctex help edit
```

を参照してください．
