# TeXstudio/インストール

[TeXstudio](/TeXstudio/) > インストール

## ダウンロード/インストール {#k39fd6e2}

### Windows, OS X, Linux {#ca4cc4c7}

- [http://www.texstudio.org/#download](http://www.texstudio.org/#download)
- [http://sourceforge.net/projects/texstudio/files/texstudio/](http://sourceforge.net/projects/texstudio/files/texstudio/)
- [http://jaist.dl.sourceforge.net/project/texstudio/texstudio/](http://jaist.dl.sourceforge.net/project/texstudio/texstudio/)
    <!-- -http://ftp.jaist.ac.jp/pub/sourceforge/t/te/texstudio/texstudio/ -->
    <!-- -ftp://ftp.jaist.ac.jp/pub/sourceforge/t/te/texstudio/texstudio/ -->

Qt 5 版の TeXstudio では，日本語を入力するとカーソルが文字の位置からずれたり日本語が重なって表示されたりする現象が発生します（[不具合情報](http://oku.edu.mie-u.ac.jp/~okumura/texwiki/?TeXstudio#ped67bdd)を参照）．

### OS X {#d9a96322}

#### Homebrew を利用してインストール {#h15f48da}

- [https://github.com/caskroom/homebrew-cask/blob/master/Casks/texstudio.rb](https://github.com/caskroom/homebrew-cask/blob/master/Casks/texstudio.rb)

```
$ brew install caskroom/cask/brew-cask
$ brew cask install texstudio
```

#### MacPortsを利用してインストール {#ef7243ed}

texstudioという名前のPortをインストールする。

```
$ sudo port install texstudio
```

### Arch Linux {#oe658c76}

- [https://www.archlinux.org/packages/?name=texstudio](https://www.archlinux.org/packages/?name=texstudio)

```
$ sudo pacman -S texstudio
```

Arch Linux の TeXstudio は Qt 5 を使用しています．
Qt 5 版の TeXstudio では，日本語を入力するとカーソルが文字の位置からずれたり日本語が重なって表示されたりする現象が発生します（[不具合情報](http://oku.edu.mie-u.ac.jp/~okumura/texwiki/?TeXstudio#ped67bdd)を参照）．

### Linux Mint/LMDE {#rb8391cd}

- [http://packages.ubuntu.com/ja/texstudio](http://packages.ubuntu.com/ja/texstudio)
- [https://packages.debian.org/ja/texstudio](https://packages.debian.org/ja/texstudio)

```
$ sudo apt-get install texstudio texstudio-l10n texstudio-doc
```

### Debian/Ubuntu {#e741d7a7}

DebianやUbuntuのTeXstudioパッケージには2種類あるが、通常はtexstudioでよい。

```
$ sudo apt-get install texstudio texstudio-l10n texstudio-doc
```

### Fedora {#t57e5bdc}

- [https://apps.fedoraproject.org/packages/texstudio](https://apps.fedoraproject.org/packages/texstudio)


### openSUSE {#a1919cbf}

- [http://software.opensuse.org/package/texstudio](http://software.opensuse.org/package/texstudio)
