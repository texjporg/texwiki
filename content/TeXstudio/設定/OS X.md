# TeXstudio/設定/OS X

[TeXstudio](/TeXstudio/) > [設定](</TeXstudio/設定/>) > OS X

<span style="color:White;background-color:#5F2F2F;">　　<strong>◆CONTENTS◆</strong>　　</span><br>

### コマンド {#a32ff532}

PDFビューアは，組み込みPDFビューアと外部PDFビューアを選択するようになっているので好きな方を選択してください．<br>
コマンドの LaTeX に設定されている latex を uplatex に変更して -src を -synctex=1 に変更します．<br>
コマンドの DviPdf に設定されている dvipdfm を dvipdfmx に変更します．<br>
コマンドの BibTeX に設定されている bibtex を upbibtex に変更します．<br>
コマンドの Biber に設定されている biber を biber --bblencoding=utf8 -u -U --output_safechars に変更します．<br>

LaTeX
: &nbsp;

: "/usr/texbin/uplatex" -synctex=1 -interaction=nonstopmode %.tex

PdfLaTeX
: &nbsp;

: "/usr/texbin/pdflatex" -synctex=1 -interaction=nonstopmode %.tex

XeLaTeX
: &nbsp;

: "/usr/texbin/xelatex" -synctex=1 -interaction=nonstopmode %.tex

LuaLaTeX
: &nbsp;

: "/usr/texbin/lualatex" -synctex=1 -interaction=nonstopmode %.tex

: "/usr/texbin/luajitlatex" -synctex=1 -interaction=nonstopmode %.tex

外部PDFビューア
: &nbsp;

: "/Applications/Skim.app/Contents/SharedSupport/displayline" @ "?am.pdf" "?c:am.tex"

DviPs
: &nbsp;

: ruby -e "cmd='/usr/texbin/dvips -Ppdf -z -f '+0x22.chr+'?am.dvi'+0x22.chr+' '+0x7c.chr+' '+'convbkmk -u'+' '+0x3e.chr+' '+0x22.chr+'?am.ps'+0x22.chr;system(cmd)"

DviPng
: &nbsp;

: "/usr/texbin/dvipng" -T tight -D 120 %.dvi

Ps2Pdf
: &nbsp;

: "/usr/local/bin/ps2pdf" %.ps

DviPdf
: &nbsp;

: "/usr/texbin/dvipdfmx" %.dvi

BibTeX
: &nbsp;

: "/usr/texbin/upbibtex" %

BibTex 8ビット
: &nbsp;

: "/usr/texbin/bibtex8" %

Biber
: &nbsp;

: "/usr/texbin/biber" --bblencoding=utf8 -u -U --output_safechars %

Makeindex
: &nbsp;

: "/usr/texbin/mendex" -U %.idx

Texindy
: &nbsp;

: "/usr/texbin/ptexindy" %.idx

: "/usr/texbin/texindy" %.idx

Makeglossary
: &nbsp;

: makeglossaries

Metapost
: &nbsp;

: "/usr/texbin/upmpost" -interaction=nonstopmode %

Asymptote
: &nbsp;

: "/usr/texbin/asy" %.asy

Ghostscript
: &nbsp;

: "/usr/local/bin/gs"

Latexmk
: &nbsp;

: "/usr/texbin/latexmk" -e "$latex=q/uplatex &#x25;&#x25;O -synctex=1 -interaction=nonstopmode &#x25;&#x25;S/" -e "$bibtex=q/upbibtex &#x25;&#x25;O &#x25;&#x25;B/" -e "$biber=q/biber &#x25;&#x25;O --bblencoding=utf8 -u -U --output_safechars &#x25;&#x25;B/" -e "$makeindex=q/mendex &#x25;&#x25;O -U -o &#x25;&#x25;D &#x25;&#x25;S/" -e "$dvipdf=q/dvipdfmx &#x25;&#x25;O -o &#x25;&#x25;D &#x25;&#x25;S/" -norc -gg -pdfdvi -silent %

SVN
: &nbsp;

: svn

SVNADMIN
: &nbsp;

: svnadmin

## Skim との連携 {#p9518b78}

### forward search {#d42e3a79}

forward search は 外部PDFビューア に以下のように設定します．<br>

```
"/Applications/Skim.app/Contents/SharedSupport/displayline" @ "?am.pdf" "?c:am.tex"
```

### inverse search {#ea54683f}

コマンド:
: /Applications/texstudio.app/Contents/MacOS/texstudio

引数:
: "%file" -line %line
