# testfont

## フォントの一覧を作成して，表示を確認する {#me3d4919}

たとえば『美文書作成入門』（第 2 版 pp. 232--233, 第 3 版付録）のような，pifont の一覧を作成したくなったら，任意のディレクトリで，

```
tex testfont
```

とコマンドを打ち，その後，ヘルプを参考にしながら

```
pzdr
\table
\end
```

（など）と打つ．
