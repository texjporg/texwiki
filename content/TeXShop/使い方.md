## 使い方 {#i4c3aa46}

### タイプセット {#b06dc45a}

タイプセットは ⌘T (Command+T) で行います．

メニューの「タイプセット」から「pdfTeX」「TeX＋DVI」「パーソナルスクリプト」をその場で切り替えられます。

### 補完 {#d711a396}

Esc キーで補完できます．<br>

### forward and inverse search {#t182c082}

forward search は エディタ上で ⌘+クリック (Command+クリック)<br>

inverse search は PDF ビューア上で ⌘+クリック (Command+クリック)<br>

### 分割ファイルでメインのファイルを指定 {#pe4ca827}

- [TeXShop の Tips](http://d.hatena.ne.jp/hrt10/20130720/1374285372)
- [TeXのソースを分割してTeXShopでタイプセット](http://hiyokoz.blogspot.jp/2012/04/textexshop.html)

ファイルの先頭に<br>

```
% !TEX root = main.tex
```

を記述すると main.tex をタイプセットの対象ファイルにしてくれます．<br>

### TeX エンジンの選択 {#d34eea26}

- [TeXShop の Tips](http://d.hatena.ne.jp/hrt10/20130720/1374285372)
- [TeXのソースを分割してTeXShopでタイプセット](http://hiyokoz.blogspot.jp/2012/04/textexshop.html)

ファイルの先頭に

```
% !TEX program = LuaLaTeX
```

を記述すると LuaLaTeX でタイプセットしてくれます．<br>
