## 設定 {#hd2204af}

### アップデート {#ic32b0b5}

以下の設定を行う前に TeXShop が最新版であるかどうか、メニューの「TeXShop」ー「アップデートを確認...」を選択して確認してください。

### プロファイルの選択 {#c0acd0ab}

日本語の組版で一般的に使用される uplatex を使用する場合は、環境設定の「内部設定」で「TeX + dvips + distiller」の項目を適切に設定する必要があります。<br>
環境設定ウィンドウ左下のポップアップから設定を選ぶと基本的な設定が完了します。<br>
設定方法は大きく分けて以下の3通りあります。<br>

- [ptex2pdf](/ptex2pdf/) (TeX Live に付属の Lua スクリプト)
- [latexmk](/Latexmk/) (TeX Live に付属の Perl スクリプト)
- シェルスクリプト (TeXShop に付属のシェルスクリプト)

さらに

- euptex/uplatex + dvipdfmx のいずれを使用するのか
- euptex/uplatex + dvips + ps2pdf のいずれを使用するのか
- pdftex/pdflatex/luatex/lualatex/luajittex/luajitlatex/xetex/xelatex のいずれを使用するのか

などによって設定は様々になります。<br>

- ptex2pdf を使用する場合は、設定プロファイルから upTeX (ptex2pdf) を選択し、必要なオプションを加えます。
- latexmk を使用する場合は、下記を参照して直接記述します。
- シェルスクリプトを使用する場合は、下記を参照して適切なスクリプトを選択または作成して実行権限を与え、設定します。

#### パーソナルスクリプトについて {#x8b6eeb6}

環境設定の「詳細」で「パーソナルスクリプト」を指定すると「pdfTeX」「TeX＋DVI」と切り替えてタイプセットできます。<br>
通常使う「TeX + dvips + distiller」で指定しているスクリプトをコピーし、適切なオプションを加えて記述します。<br>
たとえば --shell-escape を有効にしたスクリプトを準備しておけば、必要に応じて TeXShop からでも --shell-escape を用いることができます。<br>
なお、設定プロファイルで一括設定をすると「パーソナルスクリプト」は初期化されます。<br>

### シェルスクリプトの作成 {#z1cf4023}

- TeXShop には「pdfeuptex/pdfuplatex」「pdfeuptex2/pdfuplatex2」「euptex2pdf-utf8/uplatex2pdf-utf8」の3組のシェルスクリプトが付属しています。<br>
- TeXShop にシェルスクリプトが付属していない場合は、「Tex/Latex」それぞれに設定するためのシェルスクリプトを作成し、実行権限を割り当ててから「内部設定」で指定します。<br>
    たとえばpdfuplatexをnanoで作成する場合はターミナルで

    ```
    $ nano ~/Library/TeXShop/bin/pdfuplatex
    ```

    として下記のシェルスクリプトを記述し、保存してから

    ```
    $ chmod +x ~/Library/TeXShop/bin/pdfuplatex
    ```

    を実行します。

- こうして作成したシェルスクリプトを「内部設定」で指定します。

#### &#x7e;/Library/TeXShop/bin/pdfeuptex {#e75e7a51}

TeXShop には pdfeuptex が収録されています．

***

- &#x7e;/Library/TeXShop/bin/pdfeuptex

***

```
#!/bin/sh
euptex -synctex=1 -file-line-error "$1" && \
dvipdfmx "`basename "$1" .tex`" 
```

***

chmod で実行権限を付加します．

```
$ chmod +x ~/Library/TeXShop/bin/pdfeuptex
```

#### &#x7e;/Library/TeXShop/bin/euptex2pdf-utf8 {#dcc357ad}

TeXShop には euptex2pdf-utf8 が収録されています．

***

- &#x7e;/Library/TeXShop/bin/euptex2pdf-utf8

***

```
#!/bin/sh
# iNoue Koich! (modified by S. Zenitani)

export PATH=$PATH:/usr/texbin:/usr/local/bin

COMMAND=${0##*/}
PTEX=${COMMAND%2pdf-*}
ENCODE=${COMMAND#*-}
JOBNAME=${1##*/}
JOBNAME=${JOBNAME%.*}

euptex -synctex=1 -file-line-error -kanji=$ENCODE -progname=$PTEX $1 && \
dvipdfmx $JOBNAME

```

***

chmod で実行権限を付加します．

```
$ chmod +x ~/Library/TeXShop/bin/euptex2pdf-utf8
```
