# KLatexFormula

KLatexFormula は LaTeX の数式を画像ファイに出力するアプリケーションです。

- [KLatexFormula &mdash; KLatexFormula](https://klatexformula.sourceforge.io/)

### 動作環境 {#p63a9031}

Windows, macOS, Linux

### 出力形式 {#f8437b0c}

[KLatexFormula &mdash; Available Export Formats](https://klatexformula.sourceforge.io/doc/formats) を参照。

### 使い方 {#tbfbf3ca}

LaTeX で数式を記述して \[Run LaTeX\] をクリックします。
