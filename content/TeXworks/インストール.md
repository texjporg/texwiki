## ダウンロード/インストール {#t28a6277}

[http://www.tug.org/texworks/#Getting_TeXworks](http://www.tug.org/texworks/#Getting_TeXworks) または [https://github.com/TeXworks/texworks/releases/](https://github.com/TeXworks/texworks/releases/) から TeXworks を入手できます．

[http://sourceforge.net/projects/texworks.mirror/files/](http://sourceforge.net/projects/texworks.mirror/files/) から TeXworks の旧バージョンを入手できます．

[http://junk.greencherry.jp/macosx/texworks/](http://junk.greencherry.jp/macosx/texworks/) から日本語用の LaTeX の設定をメニューに追加した OS X で動作する TeXworks を入手できます．

[https://github.com/TeXworks/manual/releases/](https://github.com/TeXworks/manual/releases/) から TeXworks のマニュアルを入手できます．

### Microsoft Windows {#a2e43276}

TeX Live, W32TeX には統合環境として TeXworks が含まれています．<br>
Windows PowerShell またはコマンド プロンプトで texworks とすると，立ち上がります．<br>
TeX Live では C:\texlive\2015\tlpkg\texworks\texworks.exe, W32TeX では InstallDir/share/texworks の TeXworks.exe (例えば C:\w32tex\share\texworks\TeXworks.exe) のショートカットを作成すると，通常の GUI アプリケーションのようにマウスで立ち上げることもできます．<br>

#### Debian/Ubuntu {#x4f49c24}

DenianやUbuntuでは、TeXworksパッケージは4つに小分けされている。

```
$ apt-cache search texworks
texworks - Environment for authoring TeX (LaTeX, ConTeXt, etc) documents
texworks-help-en - English help files for TeXworks
texworks-scripting-lua - Plugin to bring Lua scripting to TeXworks
texworks-scripting-python - Plugin to bring Python scripting to TeXworks
```

取り敢えずTeXworksを利用するにはtexworksだけをインストールすればよい。

```
$ sudo apt-get install texworks
```
