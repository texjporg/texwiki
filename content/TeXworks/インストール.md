## ダウンロード/インストール {#t28a6277}

[http://www.tug.org/texworks/](http://www.tug.org/texworks/) から TeXworks を入手できます．

[http://junk.greencherry.jp/macosx/texworks/](http://junk.greencherry.jp/macosx/texworks/) から日本語用の LaTeX の設定をメニューに追加した OS X で動作する TeXworks を入手できます．

### Microsoft Windows {#a2e43276}

TeX Live, W32TeX には統合環境として TeXworks (by Jonathan Kew &amp; Stefan Löffler) が含まれています．<br>
Windows PowerShell またはコマンド プロンプトで texworks とすると，立ち上がります．<br>
TeX Live では C:\texlive\2014\tlpkg\texworks\texworks.exe, W32TeX では InstallDir/share/texworks の TeXworks.exe (例えば C:\w32tex\share\texworks\TeXworks.exe) のショートカットを作成すると，通常の GUI アプリケーションのようにマウスで立ち上げることもできます．<br>

TeXworks は SyncTeX をサポートしています．<br>
SyncTeX に関しては [SyncTeX - TeX Wiki](/SyncTeX/) を参照してください．<br>

TeXworks にはコマンドの補完機能があります．<br>
コマンド補完は，一部を入力してタブを押すと候補が表示されます．<br>
補完対象となるコマンドのリストは

```
$TEXMF\share\texworks\twdata\completion
```

の中にテキストファイルで保存されています．<br>
このファイルを編集して，カスタマイズすることも可能です．<br>

W32TeX に付属のものは，スペルチェック用の英語辞書を前もって入れてあります．<br>
詳細については，ヘルプを見てください．<br>

TeXworks 0.4.5 では，フォントを埋め込んでおくと，TeXworks の PDF viewer でゴシック体も表示できます．(→ [TeXworks#組み込みの PDF ビューアにゴシック体を表示させる](/TeXworks/#t5313ebc)を参照)<br>

W32TeX の TeXworks は pdfpLaTeX が標準になっています．<br>
この pdfpLaTeX で使用されている C:\w32tex\bin\pdfplatex.bat は以下のように記述されていると思います．<br>

```
@echo off
platex -synctex=1 -jobname="%~n1" -kanji=utf8 -guess-input-enc %1 && dvipdfmx "%~n1"
```

この処理方法の場合

- ファイルの文字コードは自動判別されます．
- コンソールへの出力や log ファイルへの出力は UTF-8 で行われます．
- SyncTeX が使用できます．
- platex でエラーが発生して x を入力すると dvipdfmx が実行されずに終了できます．
- platex でエラーが発生して e を入力すると PDF ファイルが作成されている場合に PDF ビューアがアクティブにならずにすぐにエラー行にジャンプできます．

公式サイトの Windows バイナリや TeX Live の TeXworks を使用する場合は，日本語のための設定がされていないので

- [タイプセットの設定](</TeXworks/設定/Windows/#q50d2378>)

を参考にして日本語のための設定を行います．

#### Debian/Ubuntu {#x4f49c24}

DenianやUbuntuでは、TeXworksパッケージは4つに小分けされている。

```
$ apt-cache search texworks
texworks - Environment for authoring TeX (LaTeX, ConTeXt, etc) documents
texworks-help-en - English help files for TeXworks
texworks-scripting-lua - Plugin to bring Lua scripting to TeXworks
texworks-scripting-python - Plugin to bring Python scripting to TeXworks
```

取り敢えずTeXworksを利用するにはtexworksだけをインストールすればよい。

```
$ sudo apt-get install texworks
```
