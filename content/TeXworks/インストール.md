#### Linux Mint/Debian/Ubuntu {#p69845c9}

- [Ubuntu -- パッケージ検索結果 -- texworks](https://packages.ubuntu.com/ja/texworks)
- [Debian -- パッケージ検索結果 -- texworks](https://packages.debian.org/ja/texworks)

Linux Mint/Debian/Ubuntu では、TeXworks パッケージは5つに小分けされている。

```
$ apt-cache search texworks
texworks - Environment for authoring TeX (LaTeX, ConTeXt, etc) documents
texworks-help-en - English help files for TeXworks
texworks-help-fr - French help files for TeXworks
texworks-scripting-lua - Plugin to bring Lua scripting to TeXworks
texworks-scripting-python - Plugin to bring Python scripting to TeXworks
```

取り敢えず TeXworks を利用するには texworks だけをインストールすればよい。

```
$ sudo apt install texworks
```

- [Latest Builds : “TeXworks” team](https://launchpad.net/~texworks/+archive/ppa/)
    - [Packages in “Latest Builds”](https://launchpad.net/~texworks/+archive/ppa/+packages)

        ```
        $ sudo apt install software-properties-common
        $ sudo apt-add-repository ppa:texworks/ppa
        $ sudo apt update
        $ sudo apt install texworks
        ```
