## インストール {#y6c76d8e}

### Windows {#s4be4fc1}

python.exe を C:\Python34 にインストールした場合は

```
;C:\Python34
```

を環境変数 PATH に追加します．<br>

python.exe を C:\Python33 にインストールした場合は

```
;C:\Python33
```

を環境変数 PATH に追加します．<br>
