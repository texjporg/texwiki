## インストール {#y6c76d8e}

### Windows {#s4be4fc1}

python.exe を C:\Python27 にインストールした場合は

```
;C:\Python27
```

を環境変数 PATH に追加します

python.exe を C:\Python33 にインストールした場合は

```
;C:\Python33
```

を環境変数 PATH に追加します
