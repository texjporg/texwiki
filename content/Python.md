# Python

## [Python](https://www.python.org/) {#ff8ca087}

Python は汎用スクリプト言語です．

<strong>注意</strong>：この Wiki 内項目では，TeX と関連づけた Python の利用のみ扱います．

一般的な Python の情報については外部サイトを参照してください．

TeX 関連プログラムには Python で書かれたスクリプトがあります（[PythonTeX](/PythonTeX/) など）．
これらのスクリプトを実行するには Python の処理系が必要です．

### インストール (Windows) {#y6c76d8e}

#### 本家 Windows executable installer {#vff4acd8}

本家の Windows executable installer を使用して %USERPROFILE%\AppData\Local\Programs\Python\Python37\ にインストールした場合は

```
%USERPROFILE%\AppData\Local\Programs\Python\Python37\Scripts\
```

と

```
%USERPROFILE%\AppData\Local\Programs\Python\Python37\
```

を環境変数 Path に追加します．

#### [ActivePython](http://downloads.activestate.com/ActivePython/releases/) {#e1aa7fe2}

本家版の他の選択肢としては ActivePython があります．
