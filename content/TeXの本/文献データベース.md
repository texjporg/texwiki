# TeXの本/文献データベース

## TeX の本（和書：翻訳含む）の文献データベース {#s634e2b0}

[TeXの本棚](http://hondana.org/TeX/)，[TeXの本](</TeXの本/>)を BibTeX の書式でまとめてみました。

```
%%% LuaLaTeX, XeLaTeX, upLaTeX, pLaTeX
\documentclass[autodetect-engine,dvi=dvipdfmx,ja=standard,a4paper]{bxjsarticle}
\usepackage[hyphens]{url}
\usepackage[hidelinks]{hyperref}
\begin{document}
\nocite* % 全データの表示

\bibliographystyle{junsrt} % 並び替えをしない
%\bibliographystyle{jplain}
\bibliography{jpnbook}
\end{document}
```

### 文献データベース {#le177b06}
