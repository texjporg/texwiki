# WZ EDITOR

## WZ EDITOR {#d893b76c}

## WZ EDITOR とは {#v4dc34d1}

WZ EDITOR は Windows XP, Vista, 7 で動作する国産の統合テキストエディタです。 (シェアウェア)

- [WZソフトウェア - WZエディタ / WZモバイル](http://www.wzsoft.jp/)
    公式サイト

<strong>2010年9月1日 WZ EDITOR 7 プレビュー1.0 を公開しました。</strong><br>

<strong>WZ EDITOR 7 オンライン版の先行販売開始は、2010年10月下旬に予定しています。</strong><br>

## WZ EDITOR 7 {#xeb01ab7}

- [WZ EDITOR 7](http://www.wzsoft.jp/wz7/)

WZ EDITOR 7 は、LaTeX ファイルの編集に標準機能で対応しています。

- [WZsoft > WZ エディタ 7 > 製品概要](http://www.wzsoft.jp/wz7/intro.htm)
- [WZsoft > WZ エディタ 7 > オンラインヘルプ > 論文](http://www.wzsoft.jp/wz7/help_006.htm)

「LaTeX専用メニュー」の仕様は、「[ｐ白鳥](http://staff.aist.go.jp/w.mizutani/pHackTeX.htm)」を参考にしています。

対応OS

- Windows 7 32bit / 64bit 日本語版
- Windows Vista 32bit 日本語版
- Windows XP 32bit 日本語版

> - Windows 7 64bit 日本語版は、32bit互換モードでの動作となります。
> - Windows 95, 98, Me, NT3 には対応しておりません。
> - Windows NT4, 2000での動作は、サポート対象外となります。

> WZ EDITOR 7 オンライン版「2010年10月下旬」販売開始予定<br>
> WZ EDITOR 7 パッケージ版「2010年11月下旬」販売開始予定

## WZ EDITOR 6 {#k023a395}

- [WZ EDITOR 6](http://www.wzsoft.jp/wz6/)
    - [WZ6 更新履歴](http://www.wzsoft.jp/wz6/verup/)

<strong>WZ EDITOR 6 の販売は、2010年8月31日で終了しました。</strong><br>

「LaTeX専用メニュー」の仕様は，「[ｐ白鳥](http://staff.aist.go.jp/w.mizutani/pHackTeX.htm)」を参考に作られたそうです。

WZ EDITOR 6 の LaTeX に関する機能は次のページが参考になります。

- [WZsoft &gt; WZエディタ &gt; 製品概要 # ●論文](http://www.wzsoft.jp/wz6/intro.htm#tex)
- [WZsoft &gt; WZエディタ &gt; チュートリアル &gt; 文章作成 # LaTeX](http://www.wzsoft.jp/wza/write.htm#latex)
- [WZsoft &gt; WZエディタ &gt; WZ6オンラインヘルプ &gt; LaTeXファイルの編集](http://www.wzsoft.jp/wz6/man/h014.htm)

対応 OS

- Windows XP(32bit) 日本語版
- Windows Vista(32bit) 日本語版
- Windows 7(32bit/64bit) 日本語版

※「Windows 7 64bit 日本語版」は、32bit互換モードでの動作となります。
