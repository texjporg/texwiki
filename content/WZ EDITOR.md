# WZ EDITOR

## WZ EDITOR {#d893b76c}

### WZ EDITOR とは {#v4dc34d1}

WZ EDITOR は 国産の Windows 用テキストエディタです。 (シェアウェア)

公式サイトは [WZエディタ6](http://www.wzsoft.jp/wz6/) です。

<img src="http://www.wzsoft.jp/wz6/rc27.png" alt="WZ EDITOR 6 の画面">

WZ EDITOR 6 の対応 OS は

- Windows XP(32bit) 日本語版
- Windows Vista(32bit) 日本語版
- Windows 7(32bit/64bit) 日本語版

※「Windows 7 64bit 日本語版」は、32bit互換モードでの動作となります。

: &nbsp;

※Windows 95,98,Meには対応しておりません。

: &nbsp;

※Windows NT,2000での動作はサポート対象外となります。

です。

WZ 6.0.45 から，「LaTeX」ファイルの編集に標準機能で対応しました。

「LaTeX専用メニュー」の仕様は，「[ｐ白鳥](http://staff.aist.go.jp/w.mizutani/pHackTeX.htm)」を参考に作られたそうです。

WZ EDITOR 6 の LaTeX に関する機能は次のページが参考になります。

- [WZsoft &gt; WZエディタ &gt; 製品概要 # ●論文](http://www.wzsoft.jp/wz6/intro.htm#tex)
- [WZsoft &gt; WZエディタ &gt; チュートリアル &gt; 文章作成 # LaTeX](http://www.wzsoft.jp/wza/write.htm#latex)
- [WZsoft &gt; WZエディタ &gt; WZ6オンラインヘルプ &gt; LaTeXファイルの編集](http://www.wzsoft.jp/wz6/man/h014.htm)

### WZ EDITOR 4/5 {#ma420665}

以下の TeX 用マクロが使用できます。

- [p白鳥 (ぱくちょう) pHackTeX](http://staff.aist.go.jp/w.mizutani/pHackTeX.htm) (水谷 亘 さん) 野鳥系マクロ。ライセンスは GPL。

### WZ EDITOR 1/2/3 {#vb048c09}

以下の TeX 用マクロが使用できます。

- [白鳥 (はくちょう) HackTeX](http://www.yatex.org/HackTeX/) (竹中 浩 さん) 野鳥系マクロ。ライセンスは GPL。
