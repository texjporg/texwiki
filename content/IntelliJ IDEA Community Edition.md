# IntelliJ IDEA Community Edition

## IntelliJ IDEA {#a13625a3}

IntelliJ IDEA は Java および Kotlin 開発業務向け IDE です。

IntelliJ IDEA Community Edition は IntelliJ IDEA のオープンソースのコミュニティ版です。
