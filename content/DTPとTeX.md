## DTP と TeX {#c60998c7}

DTP とは Desktop Publishing の略です．
TeX は組版システムであり，定型文書や比較的堅いレイアウトの文書を得意とします．
このため，とりわけ技術系で用いられることが多いようです．

TeX が DTP ソフトと呼ばれることは多くありませんが，
誰でも出版品質の文書を作成することができる「フリー」のツールとして利用可能です．
そこで，ここではより一般的な DTP ソフトである InDesign などのツールと TeX との関係，
およびそれらのツールと併せて TeX を上手に利用する方法をまとめてみます．
