## Yotuba TeX Editor とは {#mf365925}

Yotuba TeX Editor は Windows (Microsoft .NET Framework 3.5 以上がインストールされている環境) で動作する国産でフリーの TeX 統合環境です．<br>

- [Yotuba TeX Editor](http://www.vector.co.jp/soft/winnt/writing/se495703.html) (公式サイト)

## 設定 {#xf2f08b1}

\[ツール(T)\]-\[オプション(O)\]-\[TeX\] で設定します．<br>

初期設定は以下のようになります．<br>

TeXプログラム(platex)
: C:\w32tex\bin\platex.exe

PDFへの変換プログラム(dvipdfm)
: C:\w32tex\bin\dvipdfm.exe

画像用プログラム(ebb)
: C:\w32tex\bin\ebb.exe

目次作成用プログラム(mendex)
: C:\w32tex\bin\mendex.exe

dvipdfmx, extractbb を使用する場合は以下のように変更します．<br>

TeXプログラム(platex)
: C:\w32tex\bin\platex.exe

PDFへの変換プログラム(dvipdfm)
: C:\w32tex\bin\dvipdfmx.exe

画像用プログラム(ebb)
: C:\w32tex\bin\extractbb.exe

目次作成用プログラム(mendex)
: C:\w32tex\bin\mendex.exe
