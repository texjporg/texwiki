### 特徴 {#c007c9f5}

- EasyTeX Verson 3.30 以降は，ユニコード (UTF-16、UTF-16BE、UTF-8、UTF-8BOM)、Shit-JIS、EUC、JIS に対応しています．
- TeX の命令を色付けして表示できます．
- LaTeX コマンドをマウスで選び，クリックすることで，自動的にコマンドが挿入される補完機能を持っています．
- ヘルプには LaTeX の解説が付属しています．
- [Aspell](/Aspell/) などのスペルチェッカーが起動可能です．
- 登録されてないコマンドのメニューを新たに作ることができ，ショートカットのカスタマイズも可能です．
- IME および ATOK による再変換をサポートしています．
- [SumatraPDF](/SumatraPDF/) を使用すれば，SyncTeX による forward and inverse search も可能です．

シンプルな統合環境なので，これから TeX を使い始める方におすすめのソフトです．

## インストール {#sfc300c2}

### zip ファイル {#d9b1ceee}

zip ファイル版の場合はファイルを適当な場所に展開 (解凍) するだけでインストールは終了です．

### exe ファイル {#fac37d0f}

exe ファイル版 (インストーラー機能付き) の場合はインストーラーの指示に従ってインストールします．

## アンインストール {#l7ffd31d}

### zip ファイル {#r2a5838b}

zip ファイル版は，レジストリを使用しません．アンインストールするときはフォルダーごと削除してください．

### exe ファイル {#z3b6deb0}

exe ファイル版 (インストーラー機能付き) のアンインストールをするときは \[スタート\]-\[コントロール パネル\]-\[プログラムのアンインストール\] からアンインストールしてください．

## 不具合 {#n8975b09}

[TeXを使って数式をきれいに書こう](http://www.juen.ac.jp/math/nakagawa/texguide.html) の EasyTeX 不具合の報告 を参照．

- Unicode(UTF-16,BigEndian)
- Unicode(UTF-8)
- Unicode(UTF-8BOM)

## [dviout](/dviout/) との連携 (非推奨) {#etsa7019}

[dviout#forward and inverse search](/dviout/#ycc841a2) を参照．

EasyTeX のメニューバーより ［ｵﾌﾟｼｮﾝ(O)］ → ［TeX環境設定(T)］ と選びます．<br>
出てきたウィンドウで \[TeXOption\] タブの source special にチェックを入れます．<br>
\[ Iniファイルに保存 \] → \[ 　　<strong><span style="color:#119933;">✔</span></strong>OK　　 \] の順にクリックします．<br>

### forward search {#t49147bf}

LaTeX ソースのある領域を選択して \[ﾌｧｲﾙ(F)\]-\[コンパイル・Dviプレビュー(B)\] で DVI ファイルの該当領域にジャンプします．

### inverse search {#o80a79a1}

EasyTeX の実行ファイルである EasyTeX.exe のフルパスが C:\easytex\EasyTeX.exe である場合

[dviout for Windows](/dviout/) の \[Option\] → \[Setup Parameters...\] → \[Common\] の src: 欄に

```
`easytex easytex +%d %s``C:\easytex\EasyTeX.exe
```

と書き込んで \[Save\] → \[OK\] してください．<br>
dviout の画面をダブルクリックすると，EasyTeX が前面に出て，該当個所にジャンプします．

Version 3.240 以降は以下の形式でも OK です．

```
C:\easytex\EasyTeX.exe^s /j%d "%s"
```
