# クラスファイル一覧

## 標準的なクラスファイルの一覧 {#rf4b8ca1}

$TEXMF (= {$TEXMFLOCAL,$TEXMFMAIN,$TEXMFDIST})
は，TeX ディストリビューションによってディレクトリの構成が若干異なります。

TeX Live 2013 (Win32)
: &nbsp;

: C:\texlive\texmf-local

: C:\texlive\2013\texmf-dist

TeX Live 2013 (OS X, Linux)
: &nbsp;

: /usr/local/texlive/texmf-local

: /usr/local/texlive/2013/texmf-dist

W32TeX
: &nbsp;

: C:\w32tex\share\texmf-local

: C:\w32tex\share\texmf-dist

TeX Live, W32TeX の欄に「✔」とあるもの以外は TeX ディストリビューション本体には標準では含まれていないので，
それらのクラスファイルを使用する場合はユーザ自身で入手・インストールする必要があります．
