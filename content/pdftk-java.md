# pdftk-java

## pdftk-java {#v32u9c8e}

### はじめに {#k42vf083}

[pdftk-java](https://gitlab.com/pdftk-java/pdftk)
は PDF ファイルを編集するコマンドラインツールです。

PDF ファイルの結合，分割，並べ替え，ページ回転，ページ抽出，透かしの挿入，メタデータの追加や抽出，セキュリティの設定などが可能です。
