# Masamichi

## [『雅理』 Masamichi エディタ](http://www.tam.ne.jp/hiraba/programs/) {#re9385b5}

### Masamichi とは {#hfca40e4}

Masamichi は Windows で動作する国産でフリーの TeX 用エディタです．

簡単な表計算モードと HTML 作成機能が付いています．

Windows で使える，機能的で，軽い TeX 用のエディタがあまり無いので，[秀丸エディタ](</秀丸エディタ/>) + [WinShell](/WinShell/) + α を目標に作成されたそうです．

### 設定 {#wa3f6cb4}

\[ﾍﾙﾌﾟ(H)\]-\[設定\]

TeXの変更
: C:\w32tex\bin\eplatex.exe

dviout の選択
: C:\w32tex\dviout\dviout.exe

dvipdfmx の選択
: C:\w32tex\bin\dvipdfmx.exe

BibTex の選択
: C:\w32tex\bin\pbibtex.exe

MakeIndex の選択
: C:\w32tex\bin\mendex.exe
