# 原ノ味フォント

## 原ノ味フォント {#nfc86eb6}

「原ノ味フォント（原ノ味明朝、原ノ味角ゴシック）」 は「[源ノフォント](</源ノフォント/>)（源ノ明朝、源ノ角ゴシック）」を AJ1（Adobe-Japan1）対応フォントになるように組み替えたフォントです。
pTeX や upTeX で源ノフォントを使うと発生する各種の問題が解消できます。
源ノフォントと同じ [SIL Open Font License](https://openfontlicense.org/) （[日本語訳](https://licenses.opensource.jp/OFL-1.1/OFL-1.1.html)） のオープンソースフォントです（[フォントの埋め込みとライセンス](</フォントの埋め込みとライセンス/>)も参照）。

TeX Live 2020 以降で標準で PDF ファイルに埋め込まれる日本語フォントです。

- [GitHub - trueroad/HaranoAjiFonts: 原ノ味フォント / Harano Aji Fonts](https://github.com/trueroad/HaranoAjiFonts)
