# フォントの埋め込みとライセンス

## フォントの埋め込みとライセンス {#x49ed9c0}

PDF が文書交換フォーマットとして広く普及するとともに，フォントを文書ファイルに埋め込む機会も増えました。
また，近年の様々な Web フォントサービスの登場もあり，Web でも何らかの形でフォントを文書の表示側にダウンロードさせたいという要求は増大しています。
ここではフォントを文書に埋め込む際のライセンス上の制限に関する情報を提供します。

自宅で文書を閲覧するのみといったごく個人的なフォントの利用では，ライセンス上の制約はほとんどないと考えられますので，ここでは「フォントを埋め込んだ PDF ファイルを，特に不特定多数の人間に配布する状況」について議論します。

フォントを PDF などの文書ファイルへ埋め込み，それを配布する場合の最終的な判断は，フォントの提供元が定める規則に従ってください。
新たにフォントを入手されたときには，そのフォントに付属の EULA（エンドユーザー使用許諾契約）をよく読んで理解したうえで使用してください。

### OpenType フォント一般 {#da02bb50}

OpenType フォントにはフォントファイル中にフォントの埋め込み許可に関する情報が記載されています。
ソフトウェアプログラムは，この情報を読み取り,埋め込み可能かどうか判断することができます。
Microsoft による [OpenType の仕様書](https://docs.microsoft.com/en-us/typography/opentype/spec/os2#fstype) によると，以下の埋め込み許可フラグが設定可能となっています。

- <strong>埋め込みを許可しない</strong>：このライセンスのフォントは著作権保有者の許可なしには，いかなる形でのフォントの受け渡しを禁止しています。
- <strong>表示と印刷</strong>：フォントは表示と印刷のために用いる場合にのみ埋め込むことができます。
- <strong>編集可能</strong>："表示と印刷" に加えて文書を受け取った側はこのライセンスのフォントを含む文書を編集することができます。
- <strong>インストール可能</strong>：フォントを文書に埋め込んで配布することができ，それを受け取った側は文書の表示・印刷・編集が可能です。また受け取った側は，埋め込まれたフォントをパソコンに恒久的にインストールすることができ，そのフォントに関してフォントの元の入手者（文書の配布者）」と同じ権利を保有するとともに同じ EULA の制限を受けることになります。

これらに加え,補助的なものとして,

- <strong>サブセットを許可しない</strong>：埋め込む際にフォントのサブセット化を許可しません。
- <strong>ビットマップのみ</strong>：フォントファイル中にビットマップデータが存在する場合は，それのみ埋め込みを許可します。アウトラインデータの埋め込みは許可されません。

を設定可能です。

PDF で文書の受け手に "表示と印刷" <em>のみ</em>を許可するには，文書を暗号化により保護するしかありません。
また，OpenType の仕様書は "インストール可" の場合を除き，文書からフォントを抽出しシステムに恒久的にインストールすることを禁じています（許可された目的のために一時的にインストールすることは可能です）。

OpenType フォントファイルに記載できるフォントの埋め込み許可情報は簡易なもので，具体的な条件に関する詳細な記述はできません。特に商用利用についての付加的な条項などを記載することができないため，フォントベンダは別途，EULA などで条項を記載している可能性があります。
このため詳細については，必ずそのフォントの EULA を参照するようにしてください。

### [原ノ味フォント](</原ノ味フォント/>) {#h7d4719d}

フォントの埋め込みに関して基本的に制限ありません。

詳しくは，

- [SIL Open Font License](https://openfontlicense.org/) （[日本語訳](https://licenses.opensource.jp/OFL-1.1/OFL-1.1.html)）

を参照してください。

### IPAexフォント/IPAフォント {#xf3e57d2}

フォントの埋め込みに関しては，フォントがそれが埋め込まれた文書の表示に使われるのみにおいては，基本的に制限を受けません。

詳しくは，

- [IPAフォントライセンスv1.0 | 一般社団法人 文字情報技術促進協議会](https://moji.or.jp/ipafont/license/)

を参照してください。

### Adobe のフォント {#i7e13683}

Adobe のフォントに関しては，Adobe のサイト「[フォントのライセンス](https://helpx.adobe.com/jp/fonts/using/font-licensing.html)」を参照してください。
なお，Adobe Acrobat Reader に付属の小塚フォントは Adobe Acrobat Reader からの利用のみが可能で，他のソフトウェアで流用することは原則できませんので，注意してください。

[源ノ角ゴシック（Source Han Sans）および源ノ明朝（Source Han Serif）](</源ノフォント/>)に関しては，[SIL Open Font License](https://openfontlicense.org/) （[日本語訳](https://licenses.opensource.jp/OFL-1.1/OFL-1.1.html)）での提供となります。

### macOS (Mac) に付属のフォント {#v7d4fa37}

macOS に関しては，Apple による [Software License Agreements](https://www.apple.com/legal/sla/) (日本語のページは[ソフトウェアライセンス契約](https://www.apple.com/jp/legal/sla/)) のページを参照してください。
"[macOS Sonomaソフトウェアライセンス契約" の p.58](https://www.apple.com/legal/sla/docs/macOSSonoma.pdf#page=58) には

> E. フォント　本契約の条件に従って、お客様は、Appleソフトウェアの実行中にコンテンツを表示
> およびプリントするために、Appleソフトウェアに含まれるフォントを使用することができます。ただし、お客様は、当該フォントに付属する埋め込み制限で許可されている場合のみ、コンテンツ内にフォントを埋め込むことができます。これらの埋め込み制限は、「Font Book」>「プレビュー」>「フォント情報を表示」においてご覧になれます。

との記載があります。
ここでいう「埋め込み」は、英語版では「embed」という語が使用されています。

[Apple サポートへの問い合わせをした人のブログ](https://yaritakunai.hatenablog.com/entry/2017/01/22/201000)によれば「フォントとして頒布しない限り、macOSに付属するすべてのフォントが改変を加えないなら商用利用可能」との回答を得ているため、このブログの記載が信用できない人は自らサポートに問い合わせをすれば良いでしょう。

### フォント・フォントベンダごとの情報 {#d074a4c6}

最近ではフォントの購入を検討される場合に，PDF 等への埋め込みを前提とされている方も多いと思われます。ここでは，フォントを埋め込んだ文書を配布するにあたっての条件が明記されているフォント，およびフォントベンダの情報を紹介します。Web ページなどで利用条項が明確化されたところから購入されるほうが良いでしょう。

#### モリサワ {#u209736d}

PDF 等にフォントを埋め込んで文書を配布する場合，それが無償であっても商業利用に該当します。
この場合の利用条項については，

- [商業利用について](https://www.morisawa.co.jp/products/fonts/commercial-use/)

を参照してください。
基本的に，フォントの正規のライセンス取得者は，モリサワフォントが埋め込まれた文書を配布するにあたって，特別な契約およびそれに伴う使用許諾料を別途に必要としません。

#### ヒラギノフォント {#z1467679}

商用利用とPDF や EPUB への埋め込み，フォントの同梱については，

- [ライセンスについてのFAQ](https://www.screen.co.jp/ga_product/sento/support/licensefaq.html)

を参照してください。PDF への埋め込みは基本的に可能ですが，サブセットに限ること，EPUB などでフォントファイルそのものを同梱することはできない旨，記載があります。ただし、macOS に同梱のものについては，macOS の使用許諾書で規定されている通りです。

#### タイプバンク {#t12004ef}

フォントを埋め込んだ文書の配布は商業利用に該当します。

- [商業利用はできますか](https://www.morisawa.co.jp/support/faq/4073)

商業利用でも，基本的に，フォントの正規のライセンス取得者は，特別な契約およびそれに伴う使用許諾料を別途に必要としません。

#### Monotype {#vc263545}

Windows 付属の Times New Roman などの著作権保有者は Monotype Corporation となっています。現在は Monotype Imaging でしょうか。

- [FONT SOFTWARE END USER LICENSE AGREEMENT](https://www.monotype.com/legal/eula)

によると，

> You may embed the Font Software only into an electronic document that (i) is not a Commercial Product, (ii) is distributed in a secure format that does not permit the extraction of the embedded Font Software, and (iii) in the case where a recipient of an electronic document is able to Use the Font Software for editing, only if the recipient of such document is within your Licensed Unit.

非商用，埋め込みフォントが抽出できないこと，配布先で文書の再編集をする際には範囲が限定されること，などの条件があります。
