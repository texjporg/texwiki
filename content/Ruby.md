# Ruby

## [Ruby](https://www.ruby-lang.org/) {#ufdd9309}

Ruby は汎用スクリプト言語です．

<strong>注意</strong>：この Wiki 内項目では，TeX と関連づけた Ruby の利用のみ扱います．

一般的な Ruby の情報については外部サイトを参照してください．

TeX 関連プログラムには Ruby で書かれたスクリプトがあります（[convbkmk.rb](http://www.tug.org/svn/texlive/trunk/Master/texmf-dist/scripts/convbkmk/convbkmk.rb?view=markup) など）．
これらのスクリプトを実行するには Ruby の処理系が必要です．
また，Ruby は [PythonTeX](/PythonTeX/) でもサポートされています．

### インストール (Windows) {#yf2ae659}

#### [RubyInstaller for Windows](http://rubyinstaller.org/) {#g82e00ee}

RubyInstaller for Windows の Ruby を C:\Ruby22-x64 にインストールした場合は

```
;C:\Ruby22-x64\bin
```

を環境変数 PATH に追加します．

RubyInstaller for Windows の Ruby を C:\Ruby22 にインストールした場合は

```
;C:\Ruby22\bin
```

を環境変数 PATH に追加します．
