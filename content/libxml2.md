### Installation {#y82ea743}

#### MinGW {#e764be72}

```
$ curl -R -L -O ftp://xmlsoft.org/libxml2/libxml2-2.9.1.tar.gz
$ tar xvf libxml2-2.9.1.tar.gz
$ pushd libxml2-2.9.1
$ make
$ make install
$ popd
```
