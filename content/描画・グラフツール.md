## グラフ作成機能をもつソフト {#ge09ba68}

### フリーソフトウェア (オープンソース) {#w08a4b3d}

    （UNIX/Windows グラフ。PDF/EPS/PS/SVG/EMF 出力可。フリー）

- PLplot
    （Linux/macOS/Windows グラフ作成。PDF/EPS/PS/EPS+LaTeX/SVG 出力可 フリー LGPL）

- [giza](http://giza.sourceforge.net/)
    （Linux/macOS グラフ作成。PDF/EPS/PS/SVG 出力可 フリー GPLv2）

- [Graphviz](http://www.graphviz.org/) open source graph visualization software (Windows/Mac/Linux/Solaris フリー)
    - [dot2tex](https://github.com/kjellmf/dot2tex) A Graphviz to LaTeX converter
- [Ngraph-gtk](https://htrb.github.io/homepage/ngraph/ngraph-gtk.html) (Linux/Windows/macOS
    グラフ。Ngraph for X11 を GTK に移植したもの。PDF/EPS/PS/SVG 出力可 フリー)

- [Mayavi](http://code.enthought.com/projects/mayavi/) 3D scientific data visualization and plotting in Python (Windows/macOS/Linux フリー)
    - [mayavi documentation](http://docs.enthought.com/mayavi/mayavi/)
- [GeoGebra](https://www.geogebra.org/)
    ([Japanese - GeoGebra](https://www.geogebra.org/cms/ja), [GeoGebra日本](https://sites.google.com/site/geogebrajp/), Java, フリー, EPS/png/PSTricks/TikZ/Asymptote 出力可)

- [Eukleides](http://www.eukleides.org/)
    （a Euclidean Geometry Drawing Language:
    [日本語解説](http://www.mlb.co.jp/linux/science/eukleides/)） （UNIX/Windows
    フリー）

- [matplotlib](https://matplotlib.org/) (python 2D plotting library．フリー Python Software Foundation License)
- [RLPlot](http://rlplot.sourceforge.net/) (Linux/macOS/Windows グラフ作成．フリー GPL)
- [SciDAVis](http://scidavis.sourceforge.net/)
    (Linux/macOS/Windows データ解析・グラフ作成。フリー GPL)

- [Samurai Graph](http://samurai-graph.osdn.jp/features.html.ja)
    （Java 1.4 グラフ作成。EPS 出力可 フリー LGPL）

    （UNIX EPS 出力可 フリー，WYSIWYG インターフェイス，アンドゥができない）

- [QtiPlot](http://www.qtiplot.com/) Data Analysis and Scientific Visualisation (GPL)
    - [QtiPlot(改)](<http://phys.sci.hokudai.ac.jp/~sekika/wiki/index.php?QtiPlot(%B2%FE)>)

- [R](https://www.r-project.org/) （UNIX/Windows 統計解析・グラフ：
