# 日本語TeX開発コミュニティ

## 日本語TeX開発コミュニティ {#wbce53d7}

日本語 TeX 開発コミュニティは，コミュニティ版 TeX 関連ソフトウェアを継続的に開発しています。

- [日本語TeX開発コミュニティ](https://texjp.org/)（Japanese TeX Development Community）
    - [GitHub repositories](https://github.com/texjporg)
    - [日本語 TeX 開発コミュニティ公式ドキュメント集](https://texjporg.github.io/)
        - [TeX のインストール・設定方法](https://texjporg.github.io/install/)
        - [日本語 TeX 開発コミュニティの活動内容](https://texjporg.github.io/activities/)

コミュニティの活動に貢献したい・興味がある方はこちらをご参照ください。

- [日本語 TeX 開発コミュニティへ参加するには](https://texjporg.github.io/activities/join.html)
